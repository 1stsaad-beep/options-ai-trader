1) فلتر التقلب

كيف يُحسب عمليًا

العنصر في التطبيق (حي) في الاختبار التاريخي بلا بيانات خيارات

القاعدة النهائية — MTF-RSI Call

DATA      15-min bars and 60-min bars built from the session (09:30 start); RSI = Wilder RSI(14)
STATE     hourly RSI14 (last COMPLETED hourly bar) < 25
SEQUENCE  on 15-min: RSI14 < 25 (first oversold) -> RSI14 >= 25 (leaves) -> RSI14 < 25 again
          while the hourly RSI is still < 25 the whole time (reset if hourly >= 25)
SIGNAL    the 15-min bar that re-enters oversold -> BUY CALL at the next bar open
CONTRACT  delta ~0.50, expiry = first Friday >= entry date + 2 days (<= 8 days)
FILTER    skip if IV(contract)/RV20 > 1.3   (IV from the live chain; RV20 = 20-day close-to-close)
EXIT      underlying >= entry + 0.75 x ATR14(daily, previous day)   -> sell at next 15-min open
          underlying <= entry - 1.0 x ATR14                          -> sell at next 15-min open
          52 bars (2 sessions) without either                        -> sell at that bar's close
          never hold into expiry day
ORDERS    LIMIT at mid, improve toward the ask in small steps; never market orders
SIZE      2% of account NAV in premium per trade, max 5 open, one position per symbol
UNIVERSE  liquid single stocks with weekly options (ETFs showed no edge in 2024-26)
