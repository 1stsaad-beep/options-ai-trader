# Options AI Trader — V0.4

تطوير تدريجي لنفس مشروع V0.3: تطبيق Flutter عربي RTL وخادم FastAPI مستقل، مع تداول آلي **تجريبي داخل MockBroker فقط**. لا اتصال بوسيط أو مصدر تحليل خارجي، وLive مقفل برمجيًا. وضع `paper` هنا يعني المحاكاة المحلية؛ ليس حساب Paper لدى وسيط.

## ما أصبح متاحًا

- محركات التحليل الكمي وترتيب الفرص واختيار Call/Put تتصل الآن بالتنفيذ التجريبي بعد فحص المخاطر والمصالحة.
- أتمتة اختيارية لكل حساب، مع وقف خسارة وجني ربح وإغلاق للمملوك فقط وتسوية تحفظية للعقود المنتهية.
- معاملة ذرية للدورة، مفاتيح أوامر وتنفيذ محفوظة، استكمال التنفيذ الجزئي، منع إعادة الدخول لنفس الرمز في اليوم، وعزل الحسابات وحدودها والمجموعات المترابطة.
- واجهة استراتيجيات عربية لإعداد الأتمتة وتشغيل دورة واحدة، وإظهار النتيجة للحساب الصحيح؛ داكن وفاتح واتباع النظام.
- `GenericAnalysisAdapter` عام، للقراءة فقط مستقبلًا، ومعطل بالكامل حاليًا؛ لا يملك نموذج لغوي سلطة تنفيذ.
- الاحتفاظ بالمصدر السابق في Git عند `v0.3.0`، وبالتقارير القديمة ضمن `docs/archive/v0.3` كتاريخ غير نشط.

التحقق الفعلي: **185 اختبار Python و24 اختبار Flutter ناجحة، دون فشل أو تجاوز؛ Flutter Analyze دون مشاكل**. نتائج APK والأوامر والأدلة في [تقرير الاختبارات](docs/TEST_REPORT_V04_AR.md) و[تقرير البناء](docs/BUILD_V04.md). لا تعني هذه النتائج جاهزية للتداول المالي.

## تشغيل محلي سريع

من جذر المشروع، باستخدام Python 3.11 أو أحدث:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.lock
pip install --no-deps -e './backend[test]'
python -m pytest -q backend
python scripts/smoke_http.py
export OPTIONS_API_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
export TRADING_MODE=paper BROKER_PROVIDER=mock ENABLE_LIVE=false
export DATABASE_URL="sqlite:///$PWD/options_demo.db"
cd backend
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

أدخل الرمز الذي ولدته محليًا في التطبيق دون إرساله إلى المحادثة. مسارات `/api/*` و`/docs` و`/openapi.json` تتطلب Bearer؛ `/health` عام ولا يعرض أسرارًا. لا يحتوي APK على رمز دخول أو بيانات وسيط.

ابدأ بحساب تجريبي، فعّل رمزًا متحققًا داخل كتالوج Mock، ثم فعّل الأتمتة من إعدادات الاستراتيجيات. زر «تشغيل دورة» يطلب تنفيذًا من الخادم؛ العامل المستقل اختيار إضافي:

```sh
python -m app.worker --execute-mock --interval 30
```

تشغيل العامل دون `--execute-mock` تحليل فقط. بعد بدء أو إعادة تشغيل أي عملية تفتح Repository، يلزم إجراء مصالحة صريحة للحساب. بيانات السوق تنتهي بعد 60 ثانية وتحتاج تحديث Mock صريحًا؛ لا توجد تغذية أسعار مستمرة. السعر الافتراضي ثابت 1.00/1.05 دولار، لذلك اختبارات الخروج تستخدم تغيرات اصطناعية مضبوطة. الأتمتة تدير جميع المراكز التجريبية المملوكة في الحساب المفعّل، بما فيها اليدوية.
