## تشغيل محلي سريع

من جذر المشروع، باستخدام Python 3.11 أو أحدث:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.lock
pip install --no-deps -e './backend[test]'
python -m pytest -q backend
python scripts/smoke_http.py
export OPTIONS_API_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
export TRADING_MODE=paper BROKER_PROVIDER=mock ENABLE_LIVE=false
export DATABASE_URL="sqlite:///$PWD/options_demo.db"
cd backend
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

أدخل الرمز الذي ولدته محليًا في التطبيق دون إرساله إلى المحادثة. مسارات `/api/*` و`/docs` و`/openapi.json` تتطلب Bearer؛ `/health` عام ولا يعرض أسرارًا. لا يحتوي APK على رمز دخول أو بيانات وسيط.

ابدأ بحساب تجريبي، فعّل رمزًا متحققًا داخل كتالوج Mock، ثم فعّل الأتمتة من إعدادات الاستراتيجيات. زر «تشغيل دورة» يطلب تنفيذًا من الخادم؛ العامل المستقل اختيار إضافي:

```sh
python -m app.worker --execute-mock --interval 30
```

تشغيل العامل دون `--execute-mock` تحليل فقط. بعد بدء أو إعادة تشغيل أي عملية تفتح Repository، يلزم إجراء مصالحة صريحة للحساب. بيانات السوق تنتهي بعد 60 ثانية وتحتاج تحديث Mock صريحًا؛ لا توجد تغذية أسعار مستمرة. السعر الافتراضي ثابت 1.00/1.05 دولار، لذلك اختبارات الخروج تستخدم تغيرات اصطناعية مضبوطة. الأتمتة تدير جميع المراكز التجريبية المملوكة في الحساب المفعّل، بما فيها اليدوية.

## حدود الإصدار

- Demo محلي تمامًا: بيانات وأموال اصطناعية، يتوقف الزمن عند إغلاق التطبيق؛ لا يحتاج خادمًا أو إنترنت.
- وضع الخادم Mock منفصل واختياري، والعامل المستقل لا يزال يتطلب تشغيل خادم لاحقًا.
- لا IBKR أو وسيط حقيقي أو تفعيل Live. Generic Analysis Adapter معطل؛ شرح AI لا يستطيع إصدار أوامر.
- البارات والخيارات في Demo مولدة بقواعد اصطناعية لتجربة الواجهة والمخاطر، وليست اختبار جدوى مالية.

- ملفات الإصدارات والتقارير السابقة بقيت في Git. التاريخ الأصلي محفوظ أيضًا في `repository/`.

## واجهات V1 التجريبية

مسارات الحساب تحت `/api/accounts/{account_id}`: `decisions` و`lifecycle` و`analysis/{symbol}` للقراءة؛ `analysis/{symbol}/snapshot` لحفظ التحليل والـWave Tracker دون أوامر. `reversal` و`scaling` تقبل طلبًا منظمًا وتعيد حساب الإشارة الكمية داخليًا. `mock-option-quotes/refresh` يحدث تسعيرًا **اصطناعيًا صريحًا** للمراكز بعد تحديث مشاهدة السهم؛ لا يصالح حسابًا مجهول الحالة. `/api/readiness` يتطلب المصادقة ويميز جاهزية الخدمة عن أهلية الدخول.

المصدر الاصطناعي لتحليل الشارت ذو بداية تاريخ محفوظة. بعد 10,000 شمعة تحتاج جلسة تحليل مؤرشفة جديدة؛ لا يعاد تصفير التاريخ بصمت. بيانات الجلسات والأوقات UTC وليست تقويمًا معتمدًا للعطل أو التوقيت الصيفي للبورصة.
