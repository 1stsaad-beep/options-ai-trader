# تقرير الأمان — V0.5

نطاق الإصدار تطوير ومحاكاة فقط. لا ربط وسيط، لا IBKR Paper، لا Live، لا نشر خادم أو شراء استضافة. المستودع بقي Private.

## ما نُفذ وتحقق منه

- افتتاح Flutter في محرك محلي مستقل، بلا استيراد HTTP أو Broker داخل وحدات Demo. اختبار واجهات يمنع إنشاء HttpClient ويمر عبر الشاشات العشر دون طلب شبكة. شاشة الخادم اختيار منفصل ولا تتلقى بيانات Demo.
- منع Live وPaper وIBKR داخل إعدادات Demo؛ الإعدادات المقبولة Demo أو المراقبة فقط. قفل Live في Backend محفوظ وفحوصه السابقة أُعيد تشغيلها.
- فحص حالة الحساب والرصيد والدفاتر قبل التنفيذ؛ حالة الحساب المجهولة توقف الدخول والخروج حتى المصالحة، دون استخدام أسعار بديلة عند الانقطاع.
- مفاتيح طلب فريدة لكل حساب؛ إعادة الطلب بعد فقد الاستجابة تستعيد الأمر نفسه. الأمر المقبول والحالة المجهولة يُحفظان حتى عند عرض رسالة فشل الاستجابة.
- حجز كمية الإغلاق ومنع بيع أكثر من المملوك؛ عزل التنفيذ والإلغاء والأرصدة والمراكز بين الحسابات؛ عقود Call/Put مفردة فقط.
- احتساب الأوامر المعلقة والتنفيذ الجزئي والرسوم ضمن المخاطر النقدية. إعادة فحص التكلفة الأصلية للصفقة عند خفض الحدود أثناء التنفيذ الجزئي.
- حدود حساب ومجموعة مترابطة بأشد حد للأعضاء، والتوقف عند غموض أحد الحسابات المرتبطة. الأرباح المفتوحة لا تخفي خسائر اليوم في سياسة Demo التحفظية.
- الإيقاف الطارئ يلغي متبقي الدخول، ويحافظ على إمكانية إغلاق المملوك بعد استعادة الحالة والأسعار.
- التحقق من صيغة الحفظ والمعرفات والتواريخ ومطابقة النقد + تكلفة المراكز = رأس المال + الربح المحقق. تلف الحفظ لا يمحوه؛ فشل الحفظ يوقف المؤقت ويرجع الحالة السابقة.
- النموذج اللغوي لا يملك مسار أوامر أو صلاحية لتعديل المخاطر. التكامل الخارجي العام معطل؛ Demo يستخدم قواعد كمية فقط.
- تحسين Backtesting: قرارات خروج تُنفذ في ملاحظة لاحقة فقط، بيانات مستقبلية غير مرئية، عمولات وانزلاق وفرق أسعار، وتقييم مفقود معلن عند قدم الأسعار.
- إعداد توقيع CI لا يضع مفتاحًا في Git أو الكاش أو artifacts. الملف المؤقت بصلاحية 0600، وSecrets لا تُمرَّر إلى Pull Requests، والتنظيف يعمل دائمًا. إعداد ناقص يفشل؛ عدم وجود الأسرار ينتج APK غير موقع وموسوم بذلك. لا توقيع تطوير تلقائي خفي في release.
- فحص أنماط الأسرار والملفات الحساسة قبل الرفع لم يجد مفاتيح فعلية أو بيانات حساب تداول في المصدر الجديد. هذا فحص محدد الأنماط ومراجعة، وليس شهادة تدقيق أمني شاملة أو فحص اعتماديات خارجي.

## قيود ومخاطر متبقية

| القيد | الأثر والمتابعة |
|---|---|
| مفتاح تطوير محلي محفوظ خارج Git | استُخدم نفس المفتاح محليًا لتوقيع الناتج السحابي المرفق؛ ليس مفتاح إنتاج. يلزم حفظ مشفر دائم وضبط GitHub Secrets قبل اعتماد استمرارية التوقيع السحابي. أدوات الربط الحالية لا تتيح إنشاء هذه الأسرار؛ لم نطلبها في المحادثة. |
| SharedPreferences | بيانات اصطناعية فقط؛ ليست قاعدة معاملات مالية أو خزنة أسرار، ولا تمنع تعديل الملفات على جهاز مُخترق. مسح بيانات التطبيق يفقد Demo. |
| سعة الهاتف | لا حد ثابت لعدد الحسابات، لكن حجم دفتر الأوامر والحفظ والذاكرة قد يؤثر مع الاستخدام الطويل. سجل التشخيص يحتفظ بآخر 2000 حدث لكل حساب. |
| المحاكاة المبسطة | تقويم UTC اصطناعي، لا أحداث شركات أو ممارسة مبكرة أو assignment أو أسعار حقيقية؛ الانتهاء شطب تحفظي. لا تمثل جودة تنفيذ وسيط. |
| مخاطر يومية | Demo يستخدم خسارة اليوم المحققة والخسارة المفتوحة التحفظية، وليس نظام تقييم بدء اليوم الإنتاجي المتكامل. |
| خادم V0.4 المحفوظ | يعتمد أسعار Mock مؤقتة تحتاج تحديثًا صريحًا؛ دفتره التجريبي ليس نموذج رسوم وسيط كاملًا. فحوص الخدمة لا تثبت تحمل تشغيل طويل أو تعافي إنتاجي موزع. |
| الاعتماديات والاختبار الميداني | لا اختبار اختراق خارجي ولا اعتماد تداول حي، ولم يُختبر APK على هاتف فعلي أو iOS عبر TestFlight. |
| التوقيع والأذونات | APK تطوير قابل للتصحيح ويحتوي إذن الإنترنت للوضع الاختياري المنفصل. غياب طلبات الشبكة في Demo مُختبر برمجيًا، وليس التقاط حزم من هاتف. |

لا يجوز تحويل نجاح اختبارات المحاكاة إلى إذن بتداول مالي. تبقى أي مرحلة وسيط أو أموال أو استضافة دائمة خارج هذا الإصدار.
