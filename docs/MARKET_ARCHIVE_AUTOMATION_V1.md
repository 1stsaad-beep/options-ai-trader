# دورة أرشفة قابلة للجدولة — دون حذف

هذه إضافة اختيارية إلى migration8، لا اتصال سوق ولا استعادة تلقائية ولا تغييرات في حسابات Demo. لا خدمة أو timer فُعّلت في بيئة المستخدم.

جهّز دليلًا خاصًا مملوكًا لمستخدم التشغيل بصلاحية0700 خارج Git وملف إعدادات خاصًا يحوي DATABASE_URL. لا تضع الاتصال أو الأسرار في الأمر أو التقرير. مرّر هويات حسابات السوق صراحةً؛ لا اختيار ضمني لجميع الحسابات.

```bash
python scripts/market_archive_cycle.py /secure-backups/market --account-id ACCOUNT_UUID --reserve-mib 512
```

كل تنفيذ ينشئ دليلًا جديدًا وملفات0600، يصدر الأصول ثم يعيد التحقق من بصمتها. لا يُنشر completed.json إلا بعد نجاح جميع الحسابات. يمنع قفل محلي دورتين في دليل الوجهة نفسه. فشل الكتابة/التحقق أو نقص المساحة يُبقي الملفات للتحقيق ويعيد رمز خروج غير صفري؛ لا حذف للنسخ القديمة ولا overwrite ولا تعديل Demo. اللقطات متسقة لكل حساب على حدة، وليست لقطة مالية شاملة لحسابات متعددة.

احتياطي المساحة فحص قبل/بعد كل حساب، وليس حجزًا للقرص أو ضمانًا ضد امتلائه أثناء الكتابة؛ فشل القرص لا يبرر حذف البيانات. مجلد فاشل دون completed.json غير مقبول للاستعادة. تحفظ receipt.pending نسخة الإيصال الأصلي أيضًا عمدًا. تحقق من كل JSONL ببصمته قبل النقل والاستعادة، ولا تعتبر اسم الملف وحده دليلًا.

ملفا infra/systemd/*.example قالبان للمراجعة على Linux موجود يملكه المستخدم. اضبط المسارات والمستخدم والحسابات، وحماية ملف البيئة ونافذة الصيانة بحسب الحجم قبل تثبيتهما. توقيت المثال03:00UTC؛ لا استئناف تلقائي لموعد فات عند الإقلاع. التصدير الكامل يحجز الكتابات أثناء لقطة كل حساب، ويتكرر التاريخ في النسخ اللاحقة. راقب مدة المهمة والمساحة ورمز الخروج بمراقب مستقل. الملفات الجديدة لا تقلل حجم قاعدة البيانات.

النسخة المحلية ليست حماية من فقد المضيف. النقل المشفر خارج المضيف، مراقب فشل الجدولة، واختبار استعادة على خادم فعلي لم تُفعّل. لا شراء خادم مطلوب؛ القالب يعمل عند توفر Linux لاحقًا. النسخ الكامل لقاعدة البيانات ما زال مطلوبًا لهوية الحساب ودفاتره، ولا تُنقل أموال Demo عبر JSONL.
