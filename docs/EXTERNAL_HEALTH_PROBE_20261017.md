# External health probe — batch69

`HealthProbe` is a fixed GET-only client of the separate68 exporter. Configuration accepts only explicit HTTPS443 `/oat/v1/health`, no credentials in URL, query, fragment, alternate port or broker host suffix. Construction is offline. The token is the dedicated health token, not an owner/trading credential. No CLI/automatic polling/deployment is introduced by this batch; the durable external monitor loop follows separately.

It shares the tested pinned-connection lifecycle: public DNS answers only, at most one pending OS lookup per persistent probe instance, DNS wait<=2 seconds, whole network request<=5 seconds, original-host TLS verification/SNI, literal IP connection, no redirects or implicit retries. Response bytes<=8192, strict UTF8/JSON and duplicate/nonfinite rejection. Slow headers/body are interrupted and late decoded results discarded. Provider clients retain the immutable two-host allowlist and4/8-second budgets; no configurable provider host was added.

Each probe generates a new32-hex nonce. The reply must echo it and carry a server timestamp within the request interval plus an explicit5-second clock-skew tolerance. Mismatched/cached/stale/future/malformed/extra-field/authority responses cannot establish health. HTTP200 must carry a readable database;503 must carry unavailable database and UNKNOWN components. Component states/freshness, diagnostic codes and verified provider auth/backoff values are checked independently. A still-fresh worker auth diagnostic may coexist briefly with a cleared current auth latch; these meanings are kept separate.

Failures return fixed PROBE_AUTH_DENIED, PROBE_RATE_LIMITED, PROBE_INVALID_RESPONSE or PROBE_UNAVAILABLE with no remote health assertion. An observed database outage is a valid OBSERVED reply with databaseReadable=false, not a claim of healthy workers. No raw remote body, URL, credential or exception text enters failure output. Clock regressions fail validation. TLS authenticates the configured origin; it does not attest a compromised exporter host.
