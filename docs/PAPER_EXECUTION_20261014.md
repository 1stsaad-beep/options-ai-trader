# Explicit option execution model — batch21

`paper-option-execution-v2` is a deterministic conservative model shared by Python/Dart. It is not a verified exchange queue simulator. Fixed policy:65¢ commission plus5¢ modeled additional cost per contract per side; adverse1¢ premium slippage (×100 multiplier); at most25% of the smaller displayed bid/ask size, rounded down. A size below4 produces no modeled fill; a nonpositive stressed bid cannot manufacture a close. Quotes must pass identity, standard OCC representation, whole-cent strike, OPRA, chronology≤30s, spread, size and exact arithmetic bounds. This does not authenticate adjusted deliverables from the OCC string or supply missing Greeks.

Direct Market Paper uses the model for entry/addition/owned close when selected. The interface selects it for newly created standalone and four-comparison accounts. Existing accounts and historical receipts retain their legacy policy; changing subsequent execution policy requires a stopped account. Partial entry consumes only modeled capacity; the unfilled amount is not a durable order or permission to chase an old signal. Owned partial close retains the existing durable close intent and never opens a reversal before flat reconciliation and fresh admission.

Every modeled fill freezes the policy, requested/consumed/filled quantities, exact price, fees and cash delta. Quote capacity is derived from original account receipts (including legacy fills), not a mutable resettable counter. A later original quote or conflicting same-time quote blocks reuse. Other independent accounts keep their own simulated liquidity budgets. Restart/backup replay recomputes the receipt and consumed capacity; policy/quantity/price/fee tampering fails reconciliation without rewriting evidence.

Risk admission includes stressed entry cost and fees; owned negative marks use the currently selected modeled exit assumptions. Performance reports identify the policy. Observed-option Replay accepts validated new entry receipts and uses actual adverse entry price/fee, preserving old entry interpretation and explicit counterfactual exit assumptions. The parser was extracted unchanged into paper_time.dart to avoid a cyclic dependency.
