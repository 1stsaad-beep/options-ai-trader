## الأمن والحدود

- فحص المصدر والتاريخ على مصدر البناء:670 ملفًا نصيًا،72 commit و1029 history blob؛ **صفر أنماط أسرار مكتشفة**.24 اعتماد Python و43 Pub بلا advisory معروف وقت الفحص. هذا ليس تدقيق اختراق ولا ضمان خلو كامل؛ لا يشمل ملفات native الثنائية/نظام التشغيل.
- الهاتف يستخدم HTTPS ورمز API الخاص بالمشغّل، ويرفض redirects وHTTP البعيد والاستجابة المخالفة لهوية الحساب/سلطة التنفيذ. الرمز يتيح حسابات ذلك المشغّل؛ فصل المستخدمين وصلاحيات SaaS ليسا مضافين.
- جميع أعلام التنفيذ بالسوق تظل false. Basic indicative لا يكفي للتعبئة الوهمية بخيارات حقيقية؛ لا أسعار أو Greeks مخترعة، ولا وقف خسارة مفترض أثناء غياب السعر.
- الأرشيف يحتفظ بالأصول داخل DB. **لم تُضف طبقة cold storage أو جدولة رفع خارجية**؛ نمو القرص مستمر ويحتاج مراقبة ونسخًا مستقلة. التصدير الكبير يحجز الكتابة أثناء اللقطة. SHA-256 يكشف تغير البيانات مقارنة بالبصمة الموثوقة لكنه ليس تشفيرًا أو توقيع هوية المُصدر أو WORM ضد مدير DB.
- استعادة JSONL لا تعيد هوية الحساب/الأموال وحدها: يلزم backup كامل عند فقد DB. لا يحدّث الاستيراد cache للأسعار القديمة ولا يعيد تشغيل قرارات أو أوامر سابقة.
- التنبيهات الحالية صندوق دائم داخل API؛ Push والمراقب الخارجي للخادم بالكامل غير مضافين. لا يُدّعى تشغيل24/7 على خادم مستقل.
