# Lab19 — اتصال هاتف حقيقي قبل شراء استضافة

التاريخ: 2026-10-12. استُؤنف من الرأس الفعلي `4613a68b8c51ba585896c967d5f238c46b0bec8b` على Recovery. المستخدم أكد تثبيت APK Lab19 على Android حقيقي. **التثبيت مؤكد من المستخدم، واتصال الهاتف بالخادم غير مقبول بعد.** لم يتغير Flutter أو APK؛ استخدم Lab19 المثبت.

## سبب المهلة وحدود البيئة

`http://10.0.2.2:8000` هو عنوان خاص بمحاكي Android للوصول إلى كمبيوتر التطوير. ليس عنوان استضافة أو عنوانًا يصل إليه هاتف حقيقي تلقائيًا. Flutter يسمح بتغيير العنوان والرمز، ويرفض HTTP البعيد وإعادة توجيه الطلبات حمايةً للرمز.

البيئة الحالية لا تحتوي Docker/Podman أو PostgreSQL أو cloudflared، ولا تتاح فيها خدمة نشر منفذ عام موثوق. بيئة Python المتاحة تكفي للاختبارات. استضافة Sites المتاحة تستخدم Workers وD1/R2؛ لا تشغّل منظومة Python/PostgreSQL والعامل المستمر الحالية. لم نحول المشروع إليها أو نختلق عنوان HTTPS. GitHub CI يشغّل اختبارات حاويات مؤقتة، لكنه ليس خادمًا للهاتف ولم يُستخدم كاستضافة أو نفق.

البديل المُجهّز: **كمبيوتر موجود لديك يشغّل Docker، ونفق Cloudflare Quick Tunnel مؤقت**. لا شراء استضافة أو دومين ولا حساب Cloudflare مطلوب لهذا النوع. يجب بقاء الكمبيوتر والإنترنت والنفق عاملة. يتغير العنوان عند إعادة تشغيل النفق، ولا ضمان للاستمرارية. لا يوجد عنوان جاهز قبل تشغيله على جهازك.

## نطاق Mock والعزل

ملف `infra/compose.phone-lab.yaml` مستقل؛ لا تدمجه مع Compose قديم. يشغّل PostgreSQL16 وAPI ومحرك Market Runtime الحقيقي مع `DisabledMarketData`. ينشئ قاعدة `options_phone_lab` وحجمًا جديدًا تحت مشروع عشوائي `oat-phone-*`. شبكة داخلية تمنع خروج API والعامل إلى المزود؛ PostgreSQL دون منفذ معلن، وAPI متاح على loopback فقط في المنفذ18019. لا يوجد عامل تداول Demo أو مفاتيح وسيط أو استيراد لبيانات قديمة.

ينشأ حسابان: **Phone Lab A — Mock** و**Phone Lab B — Mock**. تحليل الأول مفعّل والثاني معطّل لتجربة العزل. تظهر أحداث `CONFIG_CHANGED` و`PHONE_LAB_READY`، وحالة العامل وتوقيتها من العملية الفعلية. **الحالة DISABLED مع نبض حديث هي النتيجة الصحيحة مع تعطيل المزود**؛ لا أسعار أو تحليلات سوق مصطنعة توصف بأنها حقيقية. اسم صيغة العقد التاريخي `alpaca_basic_data_only` ليس دليل اتصال. كل صلاحيات التنفيذ false.

مدخل API التجريبي يمنع جميع عمليات الكتابة عدا إعدادات Market Runtime والإقرار بأحداثه؛ حتى أوامر Mock وعمليات الحسابات والمخاطر محظورة. API العادي وDemo المحلي لم يتغيرا. رمز operator يمنح الوصول إلى حسابي التجربة؛ لا تدّعي التجربة عزل صلاحيات مالكين مختلفين.

## التشغيل على الكمبيوتر

المتطلبات: Git وPython3.11+ ومحرك Docker محلي مع Composev2 وcloudflared من مصدره الرسمي. الأوامر التالية لـLinux/macOS أوWSL على Windows مع تكامل Docker محلي. لا تستخدم Docker عن بُعد أو كمبيوتر عامًا. إذا كان المتاح هو الهاتف فقط، يلزم كمبيوتر موجود أو بيئة Linux أخرى مناسبة؛ هذه الجلسة لا تستضيف المنظومة.

افتح نسخة جديدة كي لا تمس نسخة عمل قديمة. استخدم مصادقتك المعتادة مع GitHub دون لصق رموزها هنا:

```bash
git clone --branch recovery/v1.0-20261011 --single-branch https://github.com/1stsaad-beep/options-ai-trader options-ai-trader-phone-lab
cd options-ai-trader-phone-lab
python3 scripts/phone_lab.py init --directory "$HOME/oat-phone-lab-20261012"
python3 scripts/phone_lab.py start --directory "$HOME/oat-phone-lab-20261012"
python3 scripts/phone_lab.py check --directory "$HOME/oat-phone-lab-20261012"
```

يجب أن تكون نتيجة start/check هي `passed`. إذا كان المجلد موجودًا فلا تعِد init ولا تحذفه؛ استخدم start/check للبيئة نفسها، أو اسم مجلد جديد لتجربة منفصلة. يتوقف البرنامج عند تعذر Docker أو إشغال18019، ولا يوقف برنامجًا آخر لتحريره. فشل start قد يترك بعض خدمات التجربة تعمل؛ أمر stop أدناه يوقف المشروع المحدد ويحفظ بياناته. لا تستخدم `docker compose down -v` أو prune.

الأداة تحجب مخرجات Compose لتجنب تسريب الأسرار. لا ترسل مخرجات `docker inspect` أو `docker compose config` أو ملفات الإعداد الخاصة. مدير Docker المحلي يستطيع رؤية بيئة الحاويات؛ لذلك يجب أن يكون الكمبيوتر موثوقًا.

## توليد الرمز وإدخاله بأمان

ينشئ init رمز API عشوائيًا بقوة192بت وكلمة مرور قاعدة مستقلة. يحفظهما خارج Git داخل دليل بصلاحيات0700 وملفات0600. لا يطبع الرمز، ولا يضعه في APK أو GitHub أو وسائط أوامر shell. لا تستخدم مفتاح Alpaca/IBKR أو كلمة مرور GitHub.

افتح **access-token.txt** من المجلد الخاص في محرر نصوص محلي على كمبيوترك. أدخل القيمة في خانة **رمز الوصول** على الهاتف دون كلمة Bearer أو مسافات. انقلها بمدير كلمات مرور موثوق تستخدمه، أو أدخلها يدويًا. لا ترسل الرمز في المحادثة أو URL أو صورة شاشة أو بريد أو مستودع. رمز الخادم في Lab19 يبقى بالذاكرة؛ قد تحتاج إدخاله مجددًا بعد إغلاق التطبيق. لا تنشر `lab.env` أو `access-token.txt`.

## عنوان HTTPS الفعلي

بعد نجاح check، افتح طرفية ثانية على الكمبيوتر نفسه:

```bash
cloudflared tunnel --url http://127.0.0.1:18019
```

انسخ **عنوان https الحقيقي الذي يطبعه cloudflared**؛ لا يوجد عنوان ثابت في هذا الدليل. افتحه في Chrome على الهاتف مع إضافة المسار `/phone-lab`. المتوقع JSON فيها `Lab19-phone-connectivity` و`provider_connected:false`، دون تحذير شهادة. هذه صفحة هوية عامة لا تعرض الحسابات أو الرمز. لا تتجاوز تحذير شهادة ولا تثبّت شهادة جذر.

في Lab19 → **اتصال الخادم المحلي أو HTTPS**:

- **عنوان الخادم:** أصل عنوان https الحقيقي فقط، دون `/phone-lab` أو `/api` ودون استعلام أو رمز.
- **رمز الوصول:** القيمة الخاصة التي ولّدتها، ثم حفظ.
- افتح **خادم السوق** واختر أحد حسابي Phone Lab. لا تستورد Demo ولا تمسح التطبيقات القديمة.

لا تستخدم `--allowed-mail` مع APK؛ فهو يتطلب مصادقة متصفح تفاعلية لا يدعمها عميل Lab19. رمز Bearer العشوائي يحمي API؛ سرية العنوان ليست بديلًا عنه. ينهي Cloudflare طبقة TLS، لذا يمر رمز التطبيق وبيانات التجربة عبره؛ استخدم بيانات Mock فقط. إيقاف النفق يلغي العنوان.

## قبول الهاتف الفعلي

| الفحص | النتيجة المتوقعة |
|---|---|
| Chrome إلى `/phone-lab` على Wi-Fi ثم بيانات الهاتف | HTTPS موثوق وهوية التجربة نفسها |
| حفظ العنوان والرمز في Lab19 | يظهر حسابا Phone Lab دون مهلة |
| شاشة خادم السوق | نبض حديث، المصدر غير مفعّل(DISABLED)، والتنفيذ مقفل |
| تعطيل/تفعيل تحليل A أو استراتيجيته | يتغير A ويظهر CONFIG_CHANGED، ولا يتغير B |
| تبديل الحساب والإقرار بحدث | أحداث الحساب المختار فقط، مع حفظ الإقرار |
| رمز خاطئ مؤقتًا ثم الصحيح | رفض401 ثم عودة الاتصال، دون إنشاء بيانات بديلة |
| إيقاف النفق ثم إعادة تشغيله وتحديث العنوان | انقطاع ظاهر ثم اتصال، دون أوامر أو تعبئات |
| مراقبة Android الاختيارية | إشعار وجلسة حتى30دقيقة وإيقاف صريح، دون وعد عند إطفاء الهاتف |
| العودة للتطبيقات القديمة | Demo القديم دون تغيير |

أرسل نتائج الفحوص أو صورة **حالة المحرك فقط** بعد إخفاء أي معلومات حساسة. لا ترسل رمز الوصول. نجاح التثبيت لا يثبت الاتصال؛ هذه الفحوص تنتظر تنفيذها على جهازك ونتيجتك.

للتحقق الإضافي من الكمبيوتر، الأمر التالي يغير إعداد A مؤقتًا ويعيده ويختبر عزل الإقرار بالأحداث. لا يرسل أوامر تداول:

```bash
python3 scripts/phone_lab.py exercise --directory "$HOME/oat-phone-lab-20261012"
```

بعد التجربة أوقف cloudflared باستخدام Ctrl+C، ثم:

```bash
python3 scripts/phone_lab.py stop --directory "$HOME/oat-phone-lab-20261012"
```

تُحفظ قاعدة البيانات والملفات الخاصة؛ لا حذف أو تنظيف آلي. لإلغاء الوصول اترك المشروع والنفق متوقفين. تجربة جديدة بمجلد جديد تولّد رمزًا وقاعدة مختلفين.

## البدائل

- كمبيوتر موجود والنفق المؤقت أعلاه: HTTPS موثوق دون شراء استضافة؛ وهو المسار المُجهّز هنا.
- USB مع `adb reverse tcp:18019 tcp:18019` وعنوان `http://127.0.0.1:18019`: تشخيص محلي بلا نفق، **وليس قبول HTTPS**. لا يختبر مراقبة Android التي تشترط HTTPS. يتطلب ADB وUSB debugging على كمبيوترك وهاتفك.
- جهاز Linux تملكه مع عنوان موثوق موجود: ممكن لاحقًا بعد ضبط الوصول والنسخ، دون ضرورة شراء خادم. شهادة Caddy الداخلية على localhost ليست موثوقة تلقائيًا لدى APK؛ لن نعطل التحقق من TLS لحل المشكلة.
