## النتائج المثبتة

- Live مقفل وIBKRAdapter معطل، لا اتصال حقيقي أو Paper ولا أوامر خارجية. GenericAnalysisAdapter معطل، ولا Mawj أو مشروع تحليل آخر أو خدمة مدفوعة.
- المخاطر تتحقق داخل قبول الأمر والتعبئة مع الحساب والمخزون والمعلق والمصالحة. BUY يتحقق من حداثة بيانات السوق، والإغلاق الآلي يتحقق من عرض السعر؛ الإغلاق اليدوي في Mock مقيد بالملكية والحساب والجلسة والكمية وحد الأمر، ولا ندعي أنه يفحص عمر عرض سوق عند كل تعبئة. صلاحية الاستراتيجية/الأتمتة/العكس تُعاد من الإعدادات الحالية مع التحقق من أصل القرار المقبول. إيصال تعبئة موجود لا يعيد التطبيق المحاسبي.
- فقدان تحليل اختياري لا يعطل خروجًا مبررًا مستقلًا. استئناف جني جزئي لا يتحول إلى بيع كامل الباقي. عند الشك لا يفتح الاتجاه المعاكس.
- في تقويم US الاختياري، رفض التعبئة خارج الجلسة وقِدم قرار BUY يمنع اختلاق تنفيذ. حفظ نية إغلاق خارج الجلسة لا يعني أنها نُفذت.
- Research observations مرتبطة بالحساب/اللقطة، immutable في SQLite وPostgreSQL، وتعتمد مصدرًا مثبتًا؛ لا يقبل العميل السعر/الوقت. wave restore يتحقق من المصدر وdigest وسجل audit ويرفض التاريخ التالف بدل إعادة ضبطه بصمت.
- CI على `67ddb6e7cf58cd59604ab7187a6864d527a69aac`: صفر نتائج أسرار في **423 ملفًا متتبعًا و28 commit و570 history blob**. الأدلة `build13-security-secret-scan.json`؛ الفحص المحلي `secret-scan-current.json` للمصدر فقط وليس history.
- تدقيق **24 اعتماد Python و43 حزمة Pub** لم يُظهر advisory معروفًا وقت التشغيل. قفل الاعتماديات لم يتغير في تصحيح اختبار الواجهة اللاحق. الأدلة `build13-security-*audit.json`، وليست ضمانًا لكل الثغرات.
- PostgreSQL backup/restore اجتاز checksum ورفض العبث والاستعادة إلى هدف جديد بمستخدم محدود، وإبطال الثقة ثم المصالحة دون إعادة إرسال.
- لا أسرار أو مفاتيح توقيع خاصة أضيفت إلى Git. بيانات اعتماد PostgreSQL داخل CI fixtures مؤقتة محلية وليست لحساب خارجي. لم يُستخدم force push أو reset --hard أو clean ولم تُحذف فروع أو سجلات.

## الحدود المفتوحة

| المجال | القيد |
|---|---|
| فحص الأنماط | لا يفك ثنائيات/أرشيفات ولا يشمل ignored/untracked أو unreachable؛ الصفر لا يثبت الخلو الشامل |
| المصادقة | Bearer لمالك واحد، دون MFA أو RBAC متعدد مستخدمين |
| تشغيل الخدمة | لا نطاق HTTPS منشور أو مراقبة مركزية أو اختبار حمل/تعافٍ طويل أو pentest |
| Android | توقيع runner Debug مؤقت؛ لا سلسلة ترقية ثابتة، لا اختبار جهاز فعلي |
| iOS | بناء غير موقع؛ لا شهادة أو Provisioning أو TestFlight |
| الانتهاء | سياسة UTC اصطناعية ونفس اليوم مرفوض؛ لا ممارسة/تخصيص/تسوية حقيقية |
| السوق والتنفيذ | بيانات اصطناعية وإلغاء Mock مؤكد داخليًا؛ لا يُنقل هذا الافتراض إلى ناقل خارجي |
| البحث | درجات Shadow تشخيصية؛ لا تمنح إذن تنفيذ أو إثبات ربحية |
| التنبيهات | سجل محلي، دون ضمان تسليم Push أو outbox/ack |

القيود ذات الأولوية موثقة في [مصفوفة المتطلبات](RECOVERY_REQUIREMENTS_V1.md). التوقيع الثابت يحتاج قناة Secrets وفق `DEVELOPMENT_SIGNING.md`؛ لا تُرسل المفاتيح في المحادثة أو تضعها في المستودع. أي اتصال IBKR لاحق يحتاج موافقة منفصلة.
