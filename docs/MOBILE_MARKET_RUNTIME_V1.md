# شاشة خادم السوق — عقد الهاتف V1

الشاشة واجهة لخادم المشروع وليست جامع أسعار أو محرك تداول على الهاتف. يظل Demo Synthetic في مخزنه ومساره الحاليين. لا تفتح الشاشة اتصال Alpaca ولا تغير موافقة الاتصال على الخادم. تشغيل تحليل حساب لا يفتح مخاطر أو تعبئات خيارات؛ Basic indicative يظل للمراقبة فقط.

## المسارات

تتطلب جميع المسارات رمز API الخاص بخادم Options AI Trader، وليس مفاتيح Alpaca. لا مفاتيح داخل APK. إعداد الاتصال الحالي يرفض HTTP البعيد وإعادة التوجيه لحماية رمز الوصول؛ استخدم HTTPS أو نفق localhost للاختبار. الرمز الحالي يخص مشغّل الخادم ويصل إلى حساباته؛ لا تُقدَّم هذه البنية كصلاحيات SaaS متعددة المستخدمين.

| المسار بعد `/api/accounts/{id}/market-runtime` | العملية |
|---|---|
| `GET /status` | config والنبض وحالة العامل وإحصاءات المقاطع وآخر مشاهدة لكل رمز/نوع، دون طلب بيانات من المزود |
| `GET /events?limit=50&before=CURSOR` | أحداث أصلية مع SHA-256 وإقرار القراءة وصفحات مرتبطة بالحساب، حتى100 في الطلب |
| `PUT /config` | enabled واستراتيجيتا breakout/pullback مع expected_version؛ تضارب409 يستلزم إعادة القراءة |
| `POST /events/{id}/ack` | إقرار قراءة idempotent، دون تغيير payload الأصلي |

schema_version=1 وaccount_id موجودان في الاستجابات. كل سلطة تنفيذ `false`: external_orders_enabled، virtual_fills_enabled، new_risk_allowed، stop_loss_execution_assumed. يحتفظ عقد قراءة الأحداث بدعم الأحداث الأصلية الأقدم التي لا تحوي schema_version. التحقق لا يعيد كتابة أي حدث.

السعر المعروض هو آخر صفقة IEX مخزنة فقط، بتوقيت `market_time` الأصلي، مع `captured_at` و`recorded_at` منفصلين. لا يُستبدل السعر المفقود بصفر ولا بسعر Demo. تعاد مراجعة صلاحية المشاهدة عند GET؛ قد يظهر سعر قديم مع علامة تقادم واضحة. حداثة heartbeat لا تعني أن السعر صالح لتنفيذ الخيارات، وIEX ليس السوق الموحد كله.

## سلوك الهاتف

- من Demo افتح واجهة الخادم الحالية، ثم «اتصال الخادم» لإعداد HTTPS ورمز API، ثم القائمة ← «خادم السوق».
- القراءة كل15ثانية أثناء ظهور التطبيق بحالة resumed، وتحديث يدوي. لا إعادة إرسال PUT/POST عند فشل الرد. تُحذف الحالة المعتمدة بعد فشل القراءة أو مغادرة التطبيق؛ لا fallback إلى Demo.
- تغيير الحساب يبطل الاستجابات المتأخرة للحساب السابق. تشغيل/إيقاف التحليل وتفعيل كل استراتيجية يحفظ نسخة إعداد الحساب المختار فقط، دون تغيير مخاطره أو قوائم الحساب الآخر.
- نجاح API منفصل عن حالة العامل؛ نبض مفقود/قديم يظهر بوضوح. مفاتيح Alpaca وموافقة الاتصال لا تُدار من الشاشة.
- الأحداث تعرض الأصل وSHA-256 وتوقيته؛ «تمت القراءة» يسجل إقرارًا منفصلًا، و«أحداث أقدم» يقرأ الصفحة التالية. هذا **صندوق API وليس Push** عند إغلاق الهاتف.

## حدود القبول

اختبارات الشاشة تستعمل Mock HTTP واستجابة فعلية من محرك Python مع مزود اصطناعي معزول، لا أسعار حساب Alpaca حقيقية. ملف `mobile/test/fixtures/market_runtime_v1.json` موسوم بمصدره الاصطناعي للاختبارات ولا يُحمّل كبيانات إنتاج في التطبيق.

الخادم الدائم وHTTPS والتفويض والتشغيل والمراقبة والنسخ الخارجية مسؤولية بيئة الاستضافة الحالية، ولم تُشترَ أو تُشغّل استضافة هنا. لا تُدّعى سلامة تشغيل24/7 على خادم مستقل قبل اختبار فعلي. لا تكتمل بهذه الشاشة خدمة التداول الوهمي بعقود خيارات حقيقية مناسبة ولا صلاحيات مستخدمين متعددين ولا Push. نتائج الاختبارات وبصمة APK تُضاف إلى تقرير التسليم بعد تنفيذ بوابتها.
