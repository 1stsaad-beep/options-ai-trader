## المحركات وBacktesting

تشغيل `python -m app.backtest` نجح فعليًا. المثال الاصطناعي يبدأ10000 وينتهي9973.40، لعقدين بسعر دخول2.01 وخروج1.89 وعمولات2.60؛ الخسارة26.60. يشمل المثال السبريد والانزلاق والعمولة ودخولًا عند الشمعة التالية، مع إشارة اختبار محقونة مرة واحدة. هذه تجربة محاسبية وليست تقييمًا لاستراتيجية أو دليل ربحية. الدليل `docs/evidence/v03/backtest-demo.json`.

## البيئات التي لم تُختبر فعليًا

| البيئة | الحالة الفعلية |
| --- | --- |
| PostgreSQL | توفر binary16.2، لكن initdb يرفضroot والتحويل إلى مستخدم غيرroot محظور في البيئة؛ لم يعمل خادم ولا اختبار تكاملPostgreSQL |
| Docker Compose | Docker غير متاح؛ لم تُبنَ الحاويات ولم تُشغّل |
| iOS/Xcode | لاmacOS؛ إعداد المصدر والبناء السحابي موجود، لم يُشغّل بناءiOS أو توقيع/TestFlight |
| GitHub Actions | ملفات مهام جاهزة؛ لاremote أو صلاحيةGitHub متاحة، لم تُشغّل خارجيًا |
| هاتف Android وTermux | لم يتوفر جهاز فعلي؛ التعليمات موجودة، لا ادعاء تثبيت/اختبار هاتف |
| IBKR/Mawj/Live | معطلة خارج نطاق الاختبار والتفعيل |

هذه حالات «لم يُشغّل» وليست اختبارات ناجحة ولاpytest skipped. اختبار PostgreSQL القابل للتشغيل لاحقًا موجود في `scripts/postgres_check.py` ومهمةchecks، مع قاعدة مؤقتة منفصلة وشرطexplicit disposable.
