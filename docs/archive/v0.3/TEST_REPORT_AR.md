# تقرير الاختبارات الفعلية — 2026-10-09

## النتيجة

**49 اختبار Python ناجح، صفر فشل، صفر تخطٍّ** في التشغيل النهائي بـ pytest9.1.1 على Python3.12. مدة التشغيل المسجلة في JUnit نحو0.506 ثانية. نجح أيضًا اختبار تشغيل Uvicorn/HTTP وعامل Shadow مستقل على قاعدة SQLite مؤقتة. لا توجد اختبارات تداول حقيقي أو ربحية مثبتة.

الأمر الفعلي، من مساحة العمل التي تحتوي المشروع:

```sh
.venv/bin/python -m pytest -q project/options-ai-trader/backend --junitxml=deliverables/test-results.xml
.venv/bin/python project/options-ai-trader/scripts/smoke_http.py
```

من جذر نسخة المشروع القابلة للتنزيل:

```sh
python -m pytest -q backend --junitxml=test-results.xml
python scripts/smoke_http.py
```

النتائج الآلية محفوظة في `docs/evidence/test-results.xml` و`docs/evidence/http-smoke.json`. يحتوي `backend/requirements.lock` إصدارات تبعيات Python المستخدمة فعليًا؛ لا يتضمن الأدوات التجريبية لتجهيز PostgreSQL أو Flutter.

## تحقق إضافي فعلي

- `pip check`: لا تعارض تبعيات مكتشف.
- تجميع مصادر Python عبر `compile`: ناجح لجميع ملفات المشروع.
- `bash -n mobile/scripts/bootstrap.sh`: ناجح. تحليل صياغة YAML لـCompose ومهمتَيCI ناجح؛ لا يعني تنفيذها.
- اختبارات HTTP الفعلية أكدت401 دونtoken، نجاح إنشاء حسابين، إرسال أمرMock وتكراره، تنفيذ جزء مرة واحدة، رفض الحالة المجهولة، المصالحة، تشغيل العامل كعملية مستقلة، والإيقاف.
- ظهر تحذير Deprecation واحد من Starlette/AnyIO TestClient؛ لم يفشل أي اختبار. ليس هذا فحص CVE أو مراجعة أمن إنتاج كاملة.
