# حالة المكونات — 2026-10-09

هذه نسخة V0.2 للمحاكاة والمراجعة. لا يوجد تداول حقيقي أو ربط حساب فعلي أو اتصال بموج. لا تعني كلمة «منفذ» أنه جاهز للإنتاج؛ المقصود شفرة قابلة للفحص والاختبار في النطاق المبيّن.

| المكون المطلوب | الحالة الحالية | ما لم يكتمل |
| --- | --- | --- |
| Technical Analysis | SMA20 وATR وتشتت العوائد واختبارات | مصادر بيانات مرخصة ومؤشرات موسعة |
| Hybrid AI | واجهة شرح اختيارية مع fallback معزول | لا مزود AI خارجي؛ لا سلطة تنفيذ للنموذج |
| Radar / Ranking | قواعد ترتيب وفرص Shadow محفوظة | فرص سوق حقيقية وتحقق من السيولة الفعلية |
| Market Regime | Trend/Range/High Volatility كمية | معايرة واختبار تاريخي على بيانات فعلية |
| Breakout / Pullback | قواعد مستقلة قابلة للاختبار | لا دليل ربحية أو walk-forward |
| Volatility Intelligence | IV المتاح والتشتت وفلتر السبريد | IV rank/term structure/Greek calculations |
| Options Selection | DTE/delta/OI/spread/freshness/multiplier | سلسلة خيارات من وسيط وqualification حقيقي |
| Account/Global Risk | قبول ذري، حجز تعرض، حدود يومية، حالة حديثة | مخاطر net liquidation/unrealized وتقويم جلسات أمريكي |
| Order Execution | أوامر Mock يدوية، تكرار/تنفيذ جزئي/إلغاء/مصالحة | تنفيذ آلي كامل أو IBKR حتى Paper |
| Portfolio Management | عقود طويلة وإغلاق المملوك ودفتر تكلفة/استحقاق | mark-to-market ووقف/هدف وخروج Intraday/Swing آلي؛ exercise/assignment |
| Backtesting / Shadow | أسعار خيارات مؤرخة، تنفيذ لاحق، تكاليف/انزلاق؛ عامل مستقل | بيانات تاريخية فعلية وإحصاءات تمويل/متانة |
| Audit / Analytics | سجل قرارات ورفض وفرص فائتة وP&L محقق | تنبيهات Push ومقاييس متقدمة وسجل غير قابل للتعديل |

الحسابات قابلة للإضافة مع مخاطر واستراتيجيات ومراقبة مستقلة. الرموز الافتراضية NVDA/AAPL/TSLA غير مفعّلة. Mock يدعم أيضًا SPY/QQQ/MSFT/AMD؛ يمكن إضافة رمز آخر غير مفعّل لكن تفعيله يحتاج مصدر تحقق مستقبلي. كتالوج خيارات المحاكاة يقبل Call/Put بمضاعف100، أسعار تنفيذ صحيحة بالدولار ضمن $50–$1000، وانتهاء الجمعة خلال90 يومًا، مع استبعاد0DTE. لا يمثل الكتالوج عقودًا حقيقية.

توجد تسع صفحات Flutter المطلوبة بالعربية RTL والثيمات: الرئيسية، الحسابات، الفرص، الأوامر/المراكز، المخاطر/الاستراتيجيات، المراقبة، التقارير/التنبيهات، القرارات، الإيقاف. صفحة التنبيهات تعرض معلومات محلية دون خدمة إرسال تنبيهات. إجراءات التطبيق ترسل معرّف الحساب صراحةً وتحتفظ بمفتاح منع التكرار عند فشل الرد.
