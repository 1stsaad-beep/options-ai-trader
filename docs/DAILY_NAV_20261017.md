# Daily paper liquidation samples — batch53

`observed-paper-daily-v1` is an owner-authenticated read-only report at `/api/observed-paper/accounts/{account}/daily-performance?start=YYYY-MM-DD&end=YYYY-MM-DD&through=N`.

The fixed sample is the last microsecond **before** the existing modeled equity-option session close. The report includes both instants. It is not an official closing price or post-settlement NAV. Events exactly at the close belong after this sample. Equal sample timestamps are applied in original sequence order. Early closes, DST, holidays and weekends use the existing versioned 2026–2027 calendar. Only completed sessions and ranges at most366 calendar days are accepted.

The entire original ledger, segments and current head are verified from genesis before any output, including pinned earlier reports and warm caches. Historical values consume only earlier accepted original option quotes, current consumption authority, and state rebuilt before each sample; quotes older than30 seconds remain missing. Missing delivery-stock marks remain missing. No candle, cost basis, future quote or settlement price supplies a substitute. Output is bounded, but verification remains O(history); persistent trusted checkpoints are still open.

Each sample carries its state version/hash; the response pins the original end event and hashes the report. A hash detects inconsistency, not provider authenticity or a DB administrator rewriting all roots. Choosing an earlier `through` excludes later recorded evidence explicitly. No SQL migrations, new events, balance changes or execution permissions result from reading.

Performance uses adjacent simple daily returns only. A gap breaks adjacent returns and invalidates full-range return/drawdown/Sharpe. Sharpe requires at least20 complete daily returns, nonzero sample standard deviation, positive return bases, explicit252-session annualization and zero modeled risk-free rate. This is not evidence of profitability; fixture results remain labeled synthetic. Daily drawdown is distinct from intraday maximum drawdown.
