## ما لا تثبته الاختبارات

اختبارات السببية تستخدم بادئات بيانات، وقممًا لا تظهر قبل تأكيدها، وفصل تدريب/اختبار في Walk-Forward. نجاحها يثبت الحالات البرمجية المحددة، ولا يثبت دقة موجات أو ربحية استراتيجية. بيانات الاختبارات اصطناعية؛ لا مجموعة خيارات تاريخية مرخصة أو سيولة حقيقية أو اختبار مالي خارج العينة واسع. لا يوصي هذا الإصدار بنسبة مخاطرة أو صفقة استثمارية.

Demo يعمل داخل الهاتف ويتوقف وقته عند انتقال التطبيق للخلفية. العامل الخلفي مستقل عند تشغيل الخادم؛ لم يُشترَ أو يُنشر خادم دائم. IBKR Paper وLive غير متاحين للتنفيذ، رغم وجود واجهات مستقبلية. بروتوكول IBKR المقترح موثق اعتمادًا على مصادره الرسمية، ولا يمثل اتصالًا فعليًا.
