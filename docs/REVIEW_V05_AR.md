# الإنجاز والنواقص — V0.5

تطوير إضافي على V0.4 داخل المستودع نفسه. احتُفظ بإصلاحات الخدمة السابقة وتاريخ الإصدارات؛ المصدر القديم في فرع `archive/v0.4` وحزمة Git الأصلية في `repository/`.

## الوظائف الحالية

| المكوّن | ما اكتمل | حدود التحقق |
|---|---|---|
| Flutter | عشر شاشات عربية RTL، مظهر داكن/فاتح/النظام، رسائل أخطاء، عرض مصدر اصطناعي، حسابات وقوائم ومخاطر واستراتيجيات وتقارير وطوارئ | اختبارات Widgets، دون هاتف فعلي |
| Demo المحلي | بلا خادم أو إنترنت افتراضيًا، حفظ متعدد الحسابات، إشارات ودخول وتنفيذ جزئي وخروج ومصالحة وحالات أعطال | محاكاة رياضية وليست سوقًا حقيقيًا؛ يتوقف بالخلفية |
| Technical / Regime | القواعد الكمية والمؤشرات وتصنيف النظام الموجودة محفوظة وقابلة للاختبار | لا معايرة ببيانات سوق مرخصة |
| Hybrid AI | فصل الشرح عن الإشارات وحماية المخاطر وفشل المزود محفوظ | لا مزود لغوي خارجي مفعل؛ لا تعلم آلي مدرب جديد |
| Radar / Ranking | اكتشاف وترتيب فرص Call/Put في Backend، وقواعد محلية مستقلة في Demo | لا تغذية سوق دائمة |
| Breakout / Pullback | قواعد كمية واختبارات، إعدادات مستقلة لكل حساب | ليست استراتيجيات مثبتة الربحية |
| Volatility / Option Selection | محركات Backend واختبارات صلاحية/عمر/انتشار الأسعار محفوظة | اختيار Demo وتقييم خياراته مبسطان اصطناعيًا |
| Risk / Global Supervisor | حدود مستقلة، مجموعات مترابطة، منع دخول مع حالة مجهولة أو تجاوز حدود | لا تحقق من buying power أو قيود وسيط حقيقي |
| Execution / Positions | MockBroker السابق محفوظ؛ Demo مستقل مع منع تكرار وحجز ملكية وإلغاء وإغلاق وعمولات وانزلاق | لا أوامر مالية خارجية |
| Shadow | مراقبة دون دخول محلي، ومحرك Shadow Backend محفوظ | لا مقارنة أمام تغذية حية |
| Backtesting | إعادة تشغيل مستقلة محليًا، وخروج سببي وإحصاءات تقييم مفقود في Python | النتائج الاصطناعية ليست دليل أداء مالي |
| Audit / Analytics | سجل قرارات وفرص مرفوضة/ضائعة وتكاليف وربح محقق ومفتوح ومنحنى إعادة تشغيل | لا منصة تنبيهات Push خارجية أو تحليلات ضريبية |
| PostgreSQL | الترحيلات والعزل والقيود والمصالحة والدورة الموسعة اختُبرت في GitHub Actions على PostgreSQL 16 | لا قاعدة أو خادم إنتاجي |
| Android / iOS | مشاريع مشتركة وخطوط بناء سحابية؛ النتيجة الفعلية والأدلة في تقرير الاختبارات | توقيع Apple وTestFlight غير متوفرين؛ توقيع GitHub الثابت ينتظر Secrets |

## أعمال تحتاج بيئة أو موافقة لاحقة

| المرحلة | تقدير عمل إضافي | لماذا لم تُعتبر مكتملة |
|---|---:|---|
| حفظ مفتاح تطوير مشفر وإدخاله إلى GitHub Secrets واختبار ترقية إصدارين | 1–3 ساعات | صلاحية إدارة أسرار/مكان حفظ دائم |
| تجربة أجهزة Android ومقاسات وإتاحة وصول وحفظ طويل | 4–8 ساعات | أجهزة/محاكيات مناسبة واختبار تثبيت فعلي |
| Apple Developer وتوقيع TestFlight وتجربة iPhone | 4–10 ساعات | حساب وشهادات وتوقيع وتوزيع، دون شراء حالي |
| معايرة بيانات تاريخية موثوقة وتقويم سوق وعمولات وسيط | 12–24 ساعة | بيانات مرخصة وقياسات خارج العينة |
| IBKR Paper: المصادقة/الاستحقاقات/المصالحة/تعبئات حقيقية تجريبية | 16–32 ساعة | مؤجل صراحة؛ لا يمكن إثباته من Mock |
| خادم دائم: أسرار ومراقبة ونسخ احتياطية وتعافي وتحمل | 12–24 ساعة | مؤجل بقرارك، ولا شراء/نشر الآن |
| تدقيق أمني وتشغيلي مستقل قبل أي نقاش تداول حي | 16–40 ساعة | عمل منفصل؛ لا يعني السماح بتفعيل Live |

هذه تقديرات جهد وليست وعودًا زمنية. لم يُوصف أي مكوّن بأنه جاهز للتداول الحقيقي أو أي استراتيجية بأنها مربحة.
