# اتصال Alpaca المباشر — Lab20

حالة هذه النسخة عند إعداد الدليل: بوابات البناء والقبول النهائية قيد التنفيذ. البصمة والتوقيع وإيصال الاختبارات تُضاف بعد فحص artifact الفعلي. لا اتصال Alpaca حقيقي أو تجربة هاتف فعلية أُجريت في Work؛ لا مفاتيح مستخدم قُرئت أو طُلبت.

## التثبيت دون فقد Lab19

Lab20 حزمة مستقلة `com.optionsaitrader.options_ai_trader.v1previewrc2b20`، كود20، اسم `Options AI Trader Lab 20`. لا تحذف Lab19 أو تمسح بياناته. يثبت Lab20 بجانبه، لا مكانه. احتفظ بملف APK القديم وصدّر نسخة Demo من داخل Lab19 قبل أي ترقية مستقبلية. لا استيراد تلقائي أو مشاركة بيانات بين الحزمتين؛ لاستعمال نسخة Demo في Lab20 استخدم مسار النسخ/المعاينة/الاستيراد الموجود، مع إبقاء الأصل. مفاتيح Alpaca لا تدخل نسخة Demo ولا تُنقل بين التطبيقات.

إذا لم تتوفر Secrets التوقيع الخاصة، يستخدم CI توقيع تطوير مؤقتًا يُذكر في إيصال التسليم. لا يضمن هذا المفتاح ترقية APK لاحق بنفس الحزمة؛ لا تزل تطبيقًا قديمًا لحل اختلاف توقيع. بناء Lab20 هو release غير debuggable، لكنه نسخة تجريبية وليس إصدار متجر مع دورة توقيع توزيع مستقرة.

## إدخال المفاتيح من الهاتف

1. افتح قائمة Demo ثم **Alpaca مباشر من الهاتف**. مسار الخادم القديم يبقى مستقلاً ويمكن الرجوع إليه. لا يلزم عنوان خادم أو Oracle أو PostgreSQL لهذه الشاشة.
2. أدخل API Key ID وAPI Secret بنفسك على الهاتف. لا ترسلهما في Work أو GitHub. اضغط حفظ؛ تُفرَّغ الخانات ولا يعيد التطبيق عرض السر المحفوظ. لا تنسخ إعدادات التطبيق الآخر أو تدوّر مفاتيحه لتجاوز تعارض اتصال.
3. اختر IEX أو SIP بحسب صلاحياتك، وRegular أو Extended، ورموزًا مفصولة بفاصلة إنجليزية مثل `NVDA,AAPL,TSLA` (حتى10). IEX بورصة واحدة؛ تغطية Extended تختلف بحسب المصدر. لا اشتراك يُشترى تلقائيًا.
4. فعّل Real Market Data، ثم اضغط **Test Connection**. هذه موافقتك داخل الهاتف لقراءة بيانات Alpaca عبر HTTPS وWebSocket. الاتصال لا يبدأ تلقائيًا عند تثبيت التطبيق أو حفظ المفاتيح.
5. تحقق من Connected، ثم صفحة السوق والمختبرات: مصدر السلسلة، وقت UTC، آخر إغلاق شمعة دقيقة مكتملة. LIVE يحتاج مصادقة فعلية وبيانات حديثة؛ لا يعني last-trade tick ولا دقة SIP عند اختيار IEX. البيانات القديمة تبقى موسومة ولا تُستبدل ببيانات Demo.
6. جرّب انقطاع الإنترنت ثم استعادته. يفقد العرض أهلية LIVE فور فقد الاتصال/تقادم القراءة، وتوجد إعادة محاولات متدرجة ومحدودة. 401/403/402/409 تتطلب مراجعة المفاتيح أو الصلاحية؛ 406 يعني اتصالًا مستخدمًا في تطبيق آخر: يتوقف Lab20 ولا يقطع ذلك الاتصال. لا تشارك المفاتيح أو صور الحقول عند الإبلاغ عن خطأ.

## ما تفعله المختبرات

OHLCV من Alpaca يغذي حسابات RSI14 rolling وMACD12/26/9 وSMA/EMA والدعم/المقاومة والأشكال الموجية والهارمونيك الموجودة. المحور الزمني UTC، والجلسة تُصفّى بتوقيت New York مع DST. لا تملأ فجوات السوق بشموع مزيفة. مخزن الرسم في الذاكرة حتى1000 شمعة لكل رمز، ويعاد طلب تاريخ محدود عند الاتصال؛ ليس أرشيفًا طويل الأمد أو backtest point-in-time.

Wave/Harmonic/Classic/Indicator/AI Confluence مختبرات بحثية. Classic يعرض الأساس الموجود ولا يدعي اكتشافًا كاملاً لكل النماذج. AI Confluence تجميع قواعد محلي، دون LLM أو توقع ربحية. تصحيحات المزود تعدّل الشمعة في العرض دون تكرارها؛ دفتر القرارات السابق يحتفظ بالقرار المسجل.

## Market Paper مستقل

- أنشئ حسابًا افتراضيًا جديدًا (10,000 USD)، واضبط المخاطرة والعقود وSL/TP/Trailing والتعزيز. كل حساب له تشغيل ودفتر ونقد ومراكز مستقلة؛ حسابات Demo لا تُقرأ أو تُنقل.
- IEX/SIP للأسهم لا يوفّران تسعير الخيار. أدخل عقد OCC مطابقًا للسهم وCall/Put. يطلب التطبيق `feed=opra` صراحةً لعرض الخيار؛ لا تحويل تلقائي إلى indicative. عند غياب الاشتراك أو عرض حديث/صالح تبقى إشارات فقط دون تعبئة.
- المحاكاة **تقريبية بحثية** حتى مع OPRA: شراء عند ask وإغلاق عند bid، عمولة افتراضية0.65 USD للعقد لكل جهة، حجم متاح وحد spread20% وحداثة30ثانية. تفترض معامل100 وعقدًا قياسيًا غير معدل؛ لا طابور أو انزلاق أو تنفيذ حقيقي أو تمرين/assignment. تاريخ العقد أو معرف OCC وحده ليس ضمانًا لشروط عقد معدّل.
- لا مركز Call وPut متعاكسان للرمز نفسه في الحساب. دايفرجنس عكسي جديد مؤكد يطلب الإغلاق أولاً، ويحفظه، ثم يراجع عرضًا جديدًا ومخاطر الفتح. فشل الإغلاق/الحفظ/البيانات يمنع العكس. عند عدم توفر سعر صالح لا يُدّعى تنفيذ وقف خسارة أو إغلاق انتهاء صلاحية.
- التقييم كل30ثانية أثناء ظهور التطبيق وبطلب يدوي. يتوقف عند مغادرة التطبيق أو إعادة تشغيله أو تغيير الاتصال. حماية المركز ليست خدمة مستمرة في الخلفية؛ الدفتر يحتفظ بالمركز المفتوح حتى يتوفر إغلاق صالح. سجل القرار حتى10,000 إدخال، وبعد الامتلاء لا يمسح سجلات قديمة لتجاوز الحد.

## الخلفية والمفاتيح

الخدمة الاختيارية تراقب الأسعار وتحسب RSI/MACD لمدة تجريبية مستهدفة30دقيقة. يلزم إذن الإشعارات والقناة؛ يظهر إشعار مع إيقاف. لا تبدأ عند إقلاع الهاتف، ولا تعيد التشغيل تلقائيًا، وتتوقف عند إنهاء المهمة/مهلة Android. وضع البطارية وDoze والشبكة قد يوقفها قبل ذلك؛ لا تعمل عند إطفاء الهاتف. Market Paper لا يعمل داخل هذه الخدمة.

القيم مشفرة بـAES-GCM، ومفتاح التشفير في Android Keystore، وملفها داخل noBackupFilesDir. النسخ التلقائي معطل في Lab20. القيم لا ترجع إلى Flutter بعد حفظها ولا تدخل Intent أو السجلات/الـAPK/Git، ولا ترسل إلى خادم المشروع. يستخدم النقل نطاقي `data.alpaca.markets` و`stream.data.alpaca.markets` فقط ومسارات القراءة المحددة، دون redirects أو أوامر تداول. تقييد التطبيق لا يقيّد صلاحية المفتاح لدى Alpaca؛ جهاز مخترق أو تطبيق معدل قد يستخرج السر في الذاكرة. لا ضمان حماية مطلقة أو تشغيل دائم.
