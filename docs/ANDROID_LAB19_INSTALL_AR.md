# تثبيت Lab19 دون فقد بيانات النسخ القديمة

هذه نسخة تطوير مستقلة: الاسم **Options AI Trader Lab 19**، الحزمة `com.optionsaitrader.options_ai_trader.v1previewrc2b19`، versionCode19. استخدم رابط وبصمة APK المقبولين في تقرير التسليم، لا ملفًا من تشغيل فاشل. لا ضمان لترقية تطبيق ذي هوية واحدة مع مفتاح CI المؤقت.

1. أبقِ Lab18 وجميع النسخ السابقة مثبتة. إذا كانت النسخة القديمة تدعم تصدير Demo، احفظ نسخة احتياطية منها في مكان خاص قبل التجربة. لا تحذف التطبيق ولا تستخدم Clear Data.
2. طابق SHA-256 مع تقرير التسليم. إذا نزلت مرفق GitHub بصيغة ZIP فاستخرج APK؛ لا تغيّر امتداد ZIP إلى APK.
3. ثبّت Lab19 كأيقونة إضافية. يمكن استخدام `adb install options-ai-trader-rc2-build19-preview.apk` دون `-r`. ألغِ إذن تثبيت التطبيقات غير المعروفة بعد الانتهاء.
4. إذا طلب الهاتف استبدال نسختك المستخدمة أو ظهر تعارض توقيع، توقف؛ لا تحذف النسخة القديمة لتجاوز التعارض.
5. افتح النسخة القديمة وتحقق من حساباتها وأرصدتها ومراكزها المحاكية. Lab19 له مخزن مستقل، ولا يستورد أو يقرأ Demo القديم تلقائيًا.
6. شاشة «خادم السوق» تستخدم خادم المشروع المتوافق وHTTPS ورمز API. لا تُدخل مفاتيح Alpaca/IBKR ولا تُفعّل إذن المزود. المحرك المستقل يحتاج جهازًا/خادمًا يعمل؛ الهاتف لا يستضيف محرك Python.
7. خيار الخلفية معطّل حتى تبدأ جلسة صراحةً وتسمح بالإشعار. راجع ANDROID_BACKGROUND_MONITOR_V1.md لتجارب الرفض والانقطاع والحسابين وإطفاء الهاتف. إغلاق المهمة/Force Stop/إعادة التشغيل يوقف المراقبة؛ حتى30 دقيقة دون ضمان عمل24/7.

التثبيت على هاتف المستخدم والتعايش وحفظ البيانات عند الانقطاع ما زال اختبارًا فعليًا مطلوبًا. لا تُحوّل نجاح بناء APK أو اختبارات Mock إلى ادعاء اختبار جهاز.
