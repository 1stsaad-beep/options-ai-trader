# جاهزية Build23 وحدود الاعتماد

Build23 مرشح قبول هندسي للمحاكاة والبيانات ضمن الحدود التالية، وليس إعلان اكتمال V1.0 أو جاهزية للتداول الحقيقي. الهوية والتوقيع والبصمة الفعلية تُسجّل في FINAL_DELIVERY بعد استخراجها من APK الناتج.

| المجال | الجاهزية القابلة للإثبات | الحد المتبقي |
|---|---|---|
| Demo Synthetic | حسابات ومراكز وأوامر ومحاكاة محلية، حفظ واستعادة واختبارات سببية وواجهة | بيانات مصطنعة؛ لا دليل ربحية أو تنفيذ سوقي |
| Alpaca مباشر | Keystore، نتيجة اتصال مرئية، أخطاء وصلاحيات، جلسة واحدة وتدرج إعادة المحاولة وربط OHLCV بالمختبرات | الاختبارات تستخدم مزودًا محاكى؛ صلاحية مفاتيح المستخدم وOPRA الفعلية تُفحص على هاتفه فقط |
| Market Paper | دفتر مستقل؛4 حسابات ×1000 دولار بإجراء صريح؛ قواعد مختلفة ومخاطر منفصلة وإغلاق جزئي وعكس مشروط وحفظ ذري على Android | تعبئات بحثية بعرض OPRA مؤهل فقط؛ دون نموذج طابور أو انزلاق واقعي أو عقود معدلة أو تسوية ممارسة |
| المخاطر والعكس | التحقق قبل القبول والتعبئة؛ رفض التزامن والتكرار؛ حفظ الكمية غير المغلقة؛ مصالحة ثم إعادة فحص الاتجاه المقابل | حدود الخسارة تمنع تعرضًا جديدًا ولا تضمن منع خسارة فجوة؛ حجب المخاطر يُفصل عن مخالفات غير مقاسة |
| المختبرات وإعادة العرض |5 مختبرات؛ فواصل مكتملة؛ طبقات وتكبير؛ أسباب ولقطات أصلية وعلامات صفقات مرتبطة بالحساب | التحليل بحثي ومحدود بنافذة الرصد؛ لا ضمان لاستمرارية ترقيم غير محدود أو تنبؤات معايرة |
| انتهاء الخيارات | منع دخول يوم آخر تداول؛ حماية إغلاق ضمن جلسة صالحة؛ إبقاء المركز المنتهي للمراجعة | الممارسة وتسليم الأسهم والتخصيص والتسوية غير منفذة؛ لا يُنشأ إغلاق أو P&L من قيمة افتراضية |
| خلفية Android | مراقبة بيانات اختيارية بإشعار وإيقاف ومدة محدودة؛ اختبارات محاكي لدورة النشاط وإطفاء الشاشة | Market Paper يتوقف خارج الواجهة؛ لا حماية مراكز مضمونة بالخلفية، ولا عمل عند إطفاء الهاتف |
| Server / Oracle | عامل مستقل واختبارات PostgreSQL وDocker والنسخ والاستعادة والتعافي بعد انقطاع قاعدة البيانات | لم يُنشر على Oracle أو يُختبر تشغيل مستمر هناك؛ لا تعديل لخادم خارجي |
| IBKR Paper | واجهة موقوفة صراحة، لا حساب أو اتصال أو أوامر | غير متصل وغير جاهز لتداول وسيط؛ يحتاج تفويضًا منفصلًا قبل أي اتصال |
| Live / أوامر Alpaca | مقفلة ولم تُرسل أوامر خارجية | ليست ضمن المرشح أو التفويض |
| Android والتوقيع | حزمة23 منفصلة تحفظ وجود التطبيقات القديمة؛ يراجع CI الهوية والتوقيع والبصمة | مفتاح ثابت فقط إن توفر في أسرار CI؛ لا استعادة لمفتاح قديم من شهادته العامة، ولا ترحيل تلقائي بين الحزم |
| iOS | مسار بناء غير موقع للمراجعة | لا توزيع دون توقيع واختبار جهاز؛ تخزين التفضيلات لا يساوي ضمانات ملف Android الذري |
| تجربة3 جلسات | تجهيز الحسابات وقالب المقارنة وحفظ الأصل؛ نتائج غير مرصودة موسومة NOT_RUN | لم تُنفذ3 جلسات سوق فعلية ولا تُستبدل باختبارات Fixtures |
