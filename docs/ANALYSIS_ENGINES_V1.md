# محركات التحليل السببي — V1

هذه إضافة إلى محركات V0.5 داخل `backend/app/intelligence/`. لم يُعد بناء
`engines.py`، ولم تُمنح الحزمة أي مرجع إلى وسيط أو محرك تنفيذ أو إعدادات مخاطر.
جميع النتائج `mode=SHADOW` و`executable=false`. درجات الأدلة ترتيب قواعد
وصفي، وليست احتمالات نجاح أو توقعات ربح.

## الواجهة

```python
from datetime import timedelta
from app.intelligence import analyze_shadow, analyze_timeframes, WaveScenarioTracker

tracker = WaveScenarioTracker()  # مستقل لكل حساب/رمز/فاصل زمني
result = analyze_shadow(
    completed_bars,             # app.engines.Bar، بترتيب زمني صارم
    as_of=observation_time,     # datetime مع timezone، لا تُقبل شموع لاحقة له
    max_age=timedelta(minutes=2),
    expected_interval=timedelta(minutes=1),  # اختياري حسب جلسة البيانات
    tracker=tracker,
)
checkpoint = tracker.to_state()  # JSON؛ يُحفظ في مخزن الخدمة المحمي
restored = WaveScenarioTracker.from_state(checkpoint)
```

`analyze_shadow` يحتاج 35 شمعة مكتملة على الأقل، ويعيد مؤشرات زمنية قابلة
لرسم الشارت، وملخص الاتجاه والحجم، والقمم المؤكدة، وهيكل السوق، وفيبوناتشي،
وسيناريوهات الموجات، ونماذج الهارمونيك، والدايفرجنس، والنماذج الكلاسيكية.
كل فترة إحماء غير مكتملة تُرجع `null`، ولا تملأ قيمًا تاريخية من المستقبل.

`analyze_timeframes(frames, as_of=..., max_age_by_frame=...)` يحلل كل فاصل
مستقلًا ويعرض توافق الموجات وتعارض الاتجاهات ومصادر الدايفرجنس. يلزم تحديد
سياسة حداثة لكل فاصل. لا يقوم بتخمين جلسات البورصة أو بإعادة تشكيل الشموع.

| Bollinger | المتوسط والانحراف المعياري السكاني مع معامل قابل للتعديل |
| VWAP | السعر النموذجي موزونًا بالحجم، وإعادة ضبط عند تاريخ UTC |
| اتجاه/قناة | انحدار خطي نافذة 20؛ ميل وR² وقناة بضعفي RMS للبواقي |

| الحجم والتقلب | حجم الشمعة مقابل متوسط الـ20 السابقة، وتشتت العوائد اللوغاريتمية لكل شمعة |

### الموجات

توجد درجات رئيسية وداخلية من عمق تأكيد مختلف، ومرشحات موجة ثالثة، وخامسة
قيد التكوين، ودافعة 1–5 مكتملة، وABC متعرجة صاعدة/هابطة. القواعد الأساسية:
الموجة الثانية لا تمحو الأولى؛ الثالثة تتجاوز نهاية الأولى؛ الرابعة لا تتداخل
مع الأولى في النموذج القياسي؛ الثالثة لا تكون الأقصر؛ الخامسة القياسية
تتجاوز الثالثة. تعاد مستويات تفعيل وإلغاء وأهداف فيبوناتشي مع كل مرشح.

`THIRD_OF_THIRD_CANDIDATE` يتطلب مرشح ثالثة داخلية في فترة الثالثة الرئيسية
وبالاتجاه نفسه، ولا يصبح معروفًا قبل تأكيد السيناريو الأب. تُحفظ بدائل مثل
تفسير الحركة نفسها كثالثة أو كـABC؛ هذا اعتراف بالتباس العد، لا إثبات لصحة أحدهما.

لا ينفذ الإصدار عدًا شاملًا لكل صور إليوت: المثلثات القطرية والموجات الخامسة
المبتورة والتصحيحات المركبة ليست نماذج مدعومة. ترتيب الأساسي والبديل يمكن أن
يتغير عند وصول دليل جديد، لكن اللقطات والأحداث السابقة لا تُعاد كتابتها.

### الهارمونيك

تُفحص نوافذ XABCD المتناوبة سعريًا وزمنيًا: Gartley وBat وButterfly وCrab
وCypher. يختبر المحرك نسب AB/XA وBC/AB وCD/BC وAD/XA، مع قواعد XC وCD/XC
الخاصة بـCypher. سماحية النسبة الافتراضية 0.03 وبحد أقصى 0.05.

للنماذج الأربعة الأولى تكون PRZ تقاطع منطقتي D مستقلتين مشتقتين من XA وBC؛
لا يكفي اقتراب نسبة واحدة. تُرفض D أو C خارج الهندسة المسموحة. النتائج تضم
كل مرشح مطابق، والنقاط والنسب ومنطقة PRZ والتفعيل والإلغاء والأهداف.

### الدايفرجنس

يدعم RSI وخط MACD للحالات الأربع: Regular Bullish/Bearish وHidden
Bullish/Bearish. تؤخذ قراءة الزخم عند مؤشر قمة السعر نفسها، لكن لا يُنشر
الدليل قبل شمعة تأكيد القمة. يُفحص التباعد الزمني وحد تغير الزخم وعدم إكمال
فترة الإحماء. النتيجة تفرض `requires_independent_strategy_confirmation`؛
الدايفرجنس وحده لا يفتح مركزًا ولا يرسل أمر خروج.

## السببية وعدم إعادة الرسم

- القمة عند `timestamp` لا تصبح متاحة إلا عند `confirmed_at` بعد عدد
  شموع التأكيد اليمنى. الرسم يجب أن يميز الموعدين.
- القمم المتساوية تُرفض؛ شمعة Outside التي تضم أعلى وأدنى قمة معًا لا
  تستخدم لاختلاق ترتيب حركتين لا تكشفه بيانات OHLC.
- سلسلة المؤشرات تحتفظ بالقيم السابقة عند إضافة شموع جديدة. ولا يُستنتج
  مؤشر قديم من نهاية السلسلة الحالية.
- إدخال شمعة مستقبلية أو غير مكتملة أو مكررة أو بيانات أقدم من السياسة
  يرفع خطأ. التحقق من فجوات البيانات متاح عند تمرير `expected_interval`.
- السيناريو الذي كسر إلغاءه بعد أن صار قابلًا للملاحظة لا يعود إلى ترتيب
  السيناريوهات النشطة بمجرد تعافي السعر.
- الاختبارات تستخدم بادئات زمنية متتابعة، وتغير البيانات اللاحقة عمدًا،
  وتقارن المؤشرات والقمم والسيناريوهات والسجل التاريخي.

## حفظ سجل السيناريوهات واستعادته

`WaveScenarioTracker` سجل أحداث غير قابل للتعديل من خلال واجهته؛ كل حدث
`DETECTED` أو `INVALIDATED` يحتوي لقطة السيناريو وقت الحدث. قراءة `events`
تعيد tuple لعناصر immutable. إضافة سيناريو جديد لا تحذف قديمًا.

`to_state()` يصدر سلسلة SHA-256 متصلة للأحداث وchecksum للحالة كاملة.
`from_state()` يتحقق من التسلسل والهويات وانتقالات الإلغاء وأزمنة التأكيد
وموعد آخر رصد، ويعيد رفض استدعاء متعارض في الوقت نفسه بعد إعادة التشغيل.
بصمات OHLCV المسجلة تمنع تعديل شمعة قديمة أو إدخال backfill في تاريخ سبق رصده
بصمت؛ ينبغي إنشاء مسار مراجعة منفصل ومعلن لتصحيح مزود بيانات بدل تعديل الماضي.

الـhashes تحقق سلامة، وليست توقيعًا ضد مهاجم قادر على إعادة حسابها. الحفظ
الدائم وعزل الحسابات والمصادقة ومسار الوصول مسؤولية الخدمة المستدعية؛ هذه
الحزمة لا تفتح قاعدة بيانات أو شبكة. ينبغي حفظ الحالة داخل لقطة غير قابلة
للاستبدال، مع مفتاح حساب/رمز/فاصل، ثم استعادتها قبل التحليل التالي.

استخدم بادئة بيانات متزايدة ذات نقطة بداية ثابتة للمحافظة على معاني مؤشرات
الشموع؛ لا تحرك نقطة البداية ثم تعيد تفسير مؤشرات القمم القديمة. عند العرض
يمكن اقتصاص الشارت دون اقتصاص تاريخ التحليل. حد استعادة checkpoint هو
100,000 حدث، ويجب أرشفة جلسات البحث الطويلة قبل تجاوزه دون مسح التاريخ.

## الحدود المتبقية

لم تُختبر هذه المحركات على بيانات IBKR أو مزود سوق حقيقي، ولم يُقاس ربح
أي استراتيجية منها. ليست اختبارات fixtures والسببية بديلًا عن معايرة خارج
العينة وWalk-Forward بعد تكاليف التنفيذ. اختيار فترات المؤشرات وسماحية
الهارمونيك ودرجات الموجة ما يزال إعدادًا بحثيًا.

القواعد الكلاسيكية قائمة محددة أعلاه وليست موسوعة أنماط؛ مخرجات الرأس
والكتفين تستخدم خط عنق محافظًا بدل انحدار رقبة معقد. VWAP اليومي UTC ليس
VWAP جلسة سوق نيويورك. تقدم الحزمة بيانات رسم ولا تنشئ واجهة Flutter بنفسها.
لا تتحقق من رموز الوسطاء أو صلاحيات البيانات ولا تستدعي LLM أو API مدفوعًا.
