# دليل Android — V1.0 RC2

هذه معاينة تطوير للمحاكاة المحلية. لا تحتاج خادمًا أو حساب تداول أو إنترنت لتجربة Demo.

1. نزّل ملف `options-ai-trader-v1.0.apk` من تسليم **RC2**، وقارن SHA-256 مع `SHA256SUMS.txt` المرافق. ملف `unsigned` الموجود أحيانًا في مخرجات CI غير قابل للتثبيت مباشرة.
2. افتح APK من مدير الملفات واسمح بتثبيت الملف من ذلك التطبيق عند طلب Android. راجع تقرير الاختبارات للتأكد من نجاح البناء الفعلي لهذا التسليم.
3. هوية المعاينة الجديدة `com.optionsaitrader.options_ai_trader.v1previewrc2`، واسمها **Options AI Trader V1 RC2**، ورقم البناء 11. هي مستقلة عن RC1 وV0.5؛ احتفظ بتثبيتهما وبياناتهما. لا تحذف إصدارًا قديمًا لحل اختلاف شهادة التوقيع.
4. يبدأ التطبيق في Demo محلي ببيانات وأسعار وأموال اصطناعية. فعّل وضع الطيران لتجربة الفصل عن الخادم.
5. تظهر أربعة حسابات في التثبيت الجديد. أضف حسابًا خامسًا، وعدّل مخاطره واستراتيجياته وقائمة مراقبته، ثم تأكد من استقلال بقية الحسابات. الرموز الافتراضية NVDA وAAPL وTSLA ليست حدًا لعدد الأسهم.
6. فعّل أتمتة الحساب التجريبي من إعداداته، وتقدم بخطوات السوق المحلية. راجع الأمر قبل التعبئة والمركز بعد التعبئة وسجل القرار. التعزيز والانعكاس يحتاجان تفعيلًا مستقلًا.
7. جرب إغلاق مركز مملوك، ووقف الخسارة والربح والمتحرك، والتنفيذ الجزئي والانقطاع وفقد الرد ثم المصالحة. الأمر أو الحساب غير المحسوم لا يجيز فتح اتجاه معاكس.
8. افتح مختبر الرسوم وأعد العرض حتى نقطة ماضية. القمم لا تظهر قبل تأكيدها، والمرشحات الموجية والهارمونيكية قد تكون فارغة؛ هذا ليس عطلًا بحد ذاته. جرب الطبقات والتكبير والتحريك.
9. افتح مختبر البحث وسجل قرارات الصفقات. أدوات Shadow لا ترسل أوامر. Option Twin يستخدم افتراضات معلنة؛ لا تتعامل مع نتيجته على أنها توقع ربح.
10. اختبر الداكن والفاتح ووضع النظام، ثم أغلق التطبيق وافتحه للتحقق من الحفظ على هاتفك. حفظ Demo محلي ولا ينتقل تلقائيًا إلى Backend أو Paper أو Live.

زمن Demo يتوقف عند انتقال التطبيق للخلفية. عامل الخادم مستقل عندما يشغّل لاحقًا؛ لم يُنشر خادم دائم خلال هذه المهمة. لا تدخل كلمات مرور وسيط في التطبيق أو المحادثة.

التوقيع الحالي عند غياب Secrets هو مفتاح تطوير مؤقت للـrunner. بناء APK وتحقق التوقيع لا يثبتان تثبيته على جهاز فعلي أو استمرارية الترقية بين المفاتيح. يلزم لاحقًا مفتاح تطوير ثابت محفوظ عبر GitHub Secrets؛ دليل `DEVELOPMENT_SIGNING.md` يشرح ذلك.

## التحقق عبر Termux (اختياري)

APK لا يحتاج Termux. للتحقق من الملف بعد تنزيله:

```bash
pkg install coreutils
termux-setup-storage
sha256sum ~/storage/downloads/options-ai-trader-v1.0.apk
```

قارن البصمة حرفيًا بالملف المرافق. لم تُجر اختبارات داخل Termux؛ البناء المعتمد يستخدم GitHub Actions أو بيئة Flutter مدعومة.
