## أخطاء ظهرت وأُصلحت أثناء التطوير

تعارض اسم نوع بيانات مع Widget Row، وأقواس ربط الواجهة، وملاحظات تنسيق Dart؛ ثم تجاوز عرض قائمة إعدادات على شاشة بعرض 390 بكسل. تعثر اختبار Python مرة بسبب رقم الإصدار السابق. أُعيد التشغيل بعد الإصلاح؛ الأعداد أعلاه للنتيجة النهائية. أظهر البناء المحلي تحذير llvm-strip لمكتبة مؤقتة، لكنه اكتمل واجتاز الناتج فحص البنية؛ الملف المسلم جاء من البناء السحابي لتفادي الاعتماد على معالجة البيئة المحلية. تعثر تشغيل أداة قراءة Manifest أولًا بسبب مسار مكتبة نظام، ثم نجح بعد ضبطه.

يوجد تحذير إهمال من FastAPI/Starlette TestClient مع httpx، ولا يُحسب فشلًا. لم تُحدَّث الاعتماديات عشوائيًا لإخفائه.
