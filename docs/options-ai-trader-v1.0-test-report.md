## التغطية وحدودها

تغطي الاختبارات عزل الحسابات والأوامر والمراكز واللقطات؛ التكرار وفقد الاستجابة والمصالحة وإعادة التشغيل والجزئيات والإلغاء؛ قفل الاتجاه والانعكاس بعد إغلاق كامل؛ تخصيص رأس المال ومخاطرة الصفقة والخسارة اليومية والتعرض العام والمرتبط؛ الرسوم المجمدة والعلامات الناقصة والقديمة؛ التعزيز والمهلة وتغير حدوده وإعادة فتح المركز؛ الوقف والربح والمتحرك والجني المرحلي والخروج الزمني والانتهاء ومنع تجاوز المملوك؛ فشل AI والسوق وLive والمحولات؛ المؤشرات والموجات والهارمونيك والدايفرجنس والسببية وحفظ Tracker؛ Option Twin وWalk-Forward وذاكرة القرار؛ API وreadiness؛ Demo بلا شبكة والحفظ والترحيل والتلف وRTL والثيمات والرسم؛ نسخ SQLite واستعادته وحراس Docker.

استُخدم PostgreSQL 16 داخل حاوية فعلية مع معاملات واتصالات مستقلة. تشمل الفحوص ترحيلات 1–4 وقيودًا وعزلًا وسباق أوامر متعاكسة وتكرارًا وحدودًا وإغلاقًا مملوكًا ولقطات غير قابلة للتعديل. اختبار Compose شغّل API وworker وPostgreSQL، وفحص التشغيل غير root وread-only، وربط API بـloopback وعدم نشر PostgreSQL، ونبض العامل و401 للمسارات المحمية ودفترًا فارغًا. لم ينشئ أوامر ثم أزال موارده الخاصة. نجاحه ليس اختبار تشغيل ممتد أو TLS/Caddy أو استعادة PostgreSQL.

### نتائج تاريخية اصطناعية

التجربة المحاسبية `backtest-synthetic.json`: دخول عند Ask وانزلاق 0.01 لكل جانب وعمولة 0.65 لكل عقد لكل جانب، ثم خروج Bid لاحقًا. صفقة مغلقة بخسارة 26.60 دولار اصطناعي وعمولات 2.60، دون مركز ختامي مختلق.

`scripts/research_demo_v1.py`: 150 مشاهدة اصطناعية لسلسلة خيار ثابتة، تدريب 40 واختبار 12 وفصل مشاهدتين، مرشحان وتسعة مقاطع اختبار. الاختيار من التدريب فقط والتنفيذ بعد القرار، مع سبريد وعمولة وانزلاق. نتيجة خارج التدريب نحو **−321.65 دولار اصطناعي**. جرى التحقق من ثبات المقاطع المكتملة عند إضافة المستقبل. الدليل `walk-forward-synthetic.json`. لا بيانات سوق حقيقية أو برهان ربحية في هاتين التجربتين.

## أعمال لم تُشغّل أو لم تُتحقق

- Flutter المحلي داخل Work تعذر بدء اختباره بسبب قيد Dart VM؛ نتائج Flutter المعلنة من CI الفعلي.
- تثبيت Android على هاتف حقيقي، واختبار ترقية وحفظ نظام التشغيل: غير منفذ.
- توقيع Android ثابت بين runners: غير مهيأ؛ مفتاح V0.5 لم يُستعد وSecrets التوقيع غائبة.
- iPhone فعلي وتوقيع Apple وTestFlight: غير منفذ.
- IBKR Paper أو Live أو مزود سوق أو LLM مدفوع: غير متصل عمدًا، ولا أوامر مالية خارجية.
- خادم دائم وتحمل ممتد وTLS/Caddy فعلي واختراق خارجي وBackup/Restore PostgreSQL: غير منفذة.
- ربحية واسعة ببيانات خيارات حقيقية مرخصة واختبارات إحصائية خارج العينة: غير منفذة.

لا توجد حالات متجاوزة داخل مجموعات pytest/Flutter النهائية الناجحة. الأعمال غير المنفذة أعلاه ليست اختبارات ناجحة ولا تُخفى ضمن العدد. تفاصيل الوظائف الجزئية والساعات المتبقية في تقرير الإنجاز، وحدود الحماية في تقرير الأمان.
