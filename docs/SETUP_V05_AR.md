# التثبيت والاختبار — Options AI Trader V0.5

## Android: تجربة بلا خادم أو إنترنت

1. نزّل `options-ai-trader-v0.5.apk` وافتحه على Android 7.0 (API 24) أو أحدث. اسم الحزمة `com.optionsaitrader.options_ai_trader`، الإصدار `0.5.0` ورقم البناء `5`.
2. عند طلب Android، اسمح بالتثبيت من التطبيق الذي فتح الملف. هذه نسخة تطوير قابلة للتصحيح وليست إصدار متجر.
3. يبدأ التطبيق مباشرة في **Demo محلي** ويُنشئ حسابًا برصيد 10,000 دولار اصطناعي. لا تدخل بيانات وسيط أو كلمة مرور أو بطاقة دفع. يمكنك تجربة وضع الطيران.
4. افتح القائمة ← الحسابات المحلية، وأضف حسابًا ثانيًا. لكل حساب قائمة مراقبة وإعدادات مستقلة. الرموز الافتراضية NVDA/AAPL/TSLA؛ يوجد كتالوج تجريبي أوسع، ولا يجري تحقق لدى وسيط.
5. من «الاستراتيجيات والإعدادات» فعّل الأتمتة للحساب المختار. اضغط «خطوة سوق محلية» مرتين: الأولى للقرار والثانية للتنفيذ. زر تشغيل الوقت يحرك ملاحظة كل 1.5 ثانية ما دام التطبيق في المقدمة.
6. راجع «الصفقات والأوامر». جرّب شراء عقود متعددة برصيد تجريبي أكبر لتجربة التنفيذ الجزئي وحدود المخاطر؛ لا تُرفع الحدود إذا رفض النظام صفقة.
7. بعد امتلاك مركز، غيّر السيناريو الاصطناعي إلى انخفاض/ارتفاع من الإعدادات، ثم تقدم خطوات لتجربة وقف الخسارة/جني الربح والإغلاق اللاحق. الأسعار اصطناعية لجميع العقود ولا تمثل سوقًا حقيقيًا.
8. من «الطوارئ واختبار الأعطال» جرّب الانقطاع أو فقد الاستجابة. تتوقف الأوامر عندما تكون الحالة مجهولة؛ استعمل المصالحة المحلية ثم استكمل. الإيقاف الطارئ يمنع الدخول ويتيح إدارة المملوك عند عودة الحالة والأسعار الموثوقة.
9. شغّل الاختبار التاريخي من التقارير. نتائجه مستقلة عن حسابك الجاري، وتحتسب الفرق بين bid/ask والعمولة والانزلاق. ليست دليل ربحية.
10. أغلق التطبيق وافتحه للتحقق على هاتفك من بقاء الحسابات والإعدادات. الزمن لا يتقدم أثناء إغلاقه. المظهر الداكن هو الافتراضي ويمكن اختيار الفاتح أو مظهر النظام.

المفاتيح الخاصة ليست في APK أو ZIP أو المستودع. Android يحتاج تطابق شهادة التوقيع لتحديث تثبيت سابق. ملف V0.5 المرفق بُني على GitHub ثم وُقّع محليًا بشهادة التطوير المحفوظة من بناء V0.4 المحلي؛ شهادة ملف V0.4 الذي بناه GitHub سابقًا مختلفة. إن ظهر تعارض توقيع، لا تحذف بيانات التطبيق السابق؛ جرّب جهازًا/ملف مستخدم منفصلًا أو احتفظ بالتثبيت السابق إلى أن تقرر كيفية نقل بياناته. لا يوجد ترحيل تلقائي لبيانات جهاز قديم أو خادم إلى Demo.

## بناء واختبار Flutter

على بيئة تطوير مدعومة بها Flutter 3.47.7 وJava 17 وAndroid SDK:

```sh
cd mobile
bash scripts/bootstrap.sh
flutter analyze
flutter test
flutter build apk --debug --build-name=0.5.0 --build-number=5
```

المفتاح الافتراضي المحلي خارج Git؛ لتوقيع ثابت سحابيًا راجع `DEVELOPMENT_SIGNING.md`. ناتج CI المسمى `unsigned` لا يمكن تثبيته قبل توقيعه الخاص. لا تضع ملف المفتاح أو قيم Secrets في محادثة أو مستودع.

## الخادم الاختياري

لا تحتاجه لتجربة Demo. الواجهة «خادم Mock اختياري» وضع مستقل، وتحتاج خادمًا تعمل عليه API؛ لا تنقل حسابات Demo أو أرصدتها إليه. من جذر المصدر:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.lock
pip install --no-deps -e './backend[test]'
python -m pytest -q backend
python scripts/smoke_http.py
```

تشغيل الخدمة محليًا وإعداد رمز API موضحان في README. لا تنشر قاعدة البيانات أو API على الإنترنت؛ لا يوجد نشر مدفوع أو دائم في هذا الإصدار. العامل Python يعمل مستقلًا عن الهاتف عند تشغيله لاحقًا، لكن Demo يعمل داخل التطبيق فقط. PostgreSQL يُختبر على قاعدة مؤقتة في GitHub Actions؛ Docker Compose المحلي لم يُشغَّل في بيئة Work.

## Termux

لتثبيت APK لا تحتاج Termux. ويمكن استخدامه للتحقق من الملف:

```sh
pkg update
pkg install coreutils
termux-setup-storage
sha256sum ~/storage/downloads/options-ai-trader-v0.5.apk
```

قارن الناتج بملف SHA256 المرفق. لم نُشغّل الاختبارات على جهاز Termux فعلي، ولا نعد بناء Flutter/Android داخله مسارًا مدعومًا هنا؛ استخدم GitHub Actions للبناء. تشغيل Backend داخل Termux تجربة منفصلة وقد يحتاج بناء اعتماديات أصلية، فلا يُقدَّم كبديل خادم دائم.

## iPhone

المشروع المشترك موجود في `mobile/ios`. يمكن ضبط Bundle Identifier عبر إدخال `bundle_id` في Workflow اليدوي أو المتغير `IOS_BUNDLE_ID`. البناء السحابي الحالي يستخدم `--no-codesign`: لا ينتج تطبيقًا قابلاً للتثبيت عبر TestFlight. يلزم لاحقًا حساب Apple Developer، ومعرّف تطبيق وشهادة/ملف Provisioning وتوقيع وتوزيع معتمد. لا شهادات Apple أو حسابات مدفوعة استُخدمت خلال هذه المهمة. الحالة الفعلية للبناء في تقرير الاختبارات.
