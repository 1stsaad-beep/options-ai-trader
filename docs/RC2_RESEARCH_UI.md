# RC2: واجهات البحث التجريبي

## المنفذ

أضيفت صفحة **مختبر الأبحاث المحلي** إلى Flutter دون تغيير صفحات التطبيق السابقة أو دفتر التنفيذ. الحساب المحدد هو نطاق جميع المراكز والأوامر وذاكرة القرار. لا تستورد حسابات البحث أو حساباته API أو HTTP، ولا تستدعي تنفيذ الأوامر أو تعديل المخاطر.

- **Scenario Battle:** ترتيب ثلاث حالات وفق إغلاق سابق ومتوسط 20 ملاحظة. الدرجات قواعد توضيحية وليست احتمالات معايرة.
- **Entry timing:** مقارنة مبكر/مؤكد/تراجع وفق الإشارات المحلية الحالية وملف الحساب، مع تفعيل وإلغاء ومدة صلاحية. لا يغير اختيار البحث استراتيجية التنفيذ.
- **Option Twin:** سيناريوهات سعر/وقت/IV لعقد واحد مع Greeks تعليمية معلنة، السبريد، انزلاق الجانبين، والعمولتين. حد السيناريو سبعة أيام و±10% سعر و±15 نقطة IV. التقريب لا يعالج تغير Greeks أو الممارسة أو انتهاء العقد؛ لا يمثل تسعير السوق.
- **Liquidity Trap:** فشل اختراق/كسر عند الإغلاق والحجم والجسم الصغير بقواعد OHLCV؛ لا ادعاء بوجود دفتر أوامر أو كشف تلاعب فعلي.
- **Correlation Guard:** ارتباط عوائد السهم الاصطناعي لـ20 ملاحظة للرموز ذات تعرض مملوك أو شراء معلق في الحساب فقط. لا تصفير بين Call وPut، ولا تعويض للبيانات الناقصة بارتباط صفر.
- **Strategy Tournament:** تدريب على 20 فترة، فصل فترة، اختبار ثماني فترات. الاختيار بين متابعة الزخم وعكسه، ويستخدم كل تنبؤ إغلاقًا سابقًا. تكلفة افتراضية 10 نقاط أساس لكل فترة؛ النتيجة عائد سهم اصطناعي، وليست استراتيجية خيارات أو دليل ربحية.
- **Safety/Trust:** عرض بوابات تشخيصية مع أسباب الفشل. أي فشل ظاهر يخفض الدرجة إلى صفر. حتى 100 لا يمنح إذن تداول، ولا يحل محل Risk Engine.
- **Decision Memory:** قراءة لقطة القرار الأصلية والأسباب الأصلية وعمليات التنفيذ للحساب. لا تفسير لاحق مصطنع.

أضيفت صفحة **مختبر الأبحاث في الخادم** منفصلة تمامًا عن Demo. تستدعي GET فقط على `/api/accounts/{id}/research/{symbol}` وتعرض المحركات السبعة. تُرفض استجابة تحمل حسابًا/رمزًا مختلفين أو مصدرًا غير اصطناعي أو صلاحية تنفيذ، وتُسقط الاستجابات القديمة باستخدام generation والحساب والرمز. قراءة Backend لا تنقل بيانات Demo.

## الحدود المتبقية

- **Counterfactual محلي**: غير محسوب؛ لا توجد سلسلة أسعار الخيار التاريخية الكاملة محفوظة. تُظهر الواجهة ذلك صراحة و`counterfactual_pnl=null` بدل إعادة توليد أسعار قد تتغير بتغيير السيناريو.
- **Snapshots/Counterfactual Backend**: الوظائف في API؛ واجهة الهاتف الحالية تعرض GET دون كتابة أو زر Replay للخادم.
- التحليلات المحلية مبسطة ومستقلة عن Backend؛ لا ادعاء بتطابقها الكامل.
- لا بيانات حقيقية أو IBKR أو تحليل خارجي أو AI مدفوع. لا تؤثر الشاشات في Live المقفل.

## التحقق

أضيفت `research_analysis_test.dart` (11 اختبار وحدة) و`research_widget_test.dart` (4 اختبارات واجهة): عدم تعديل الدفتر، انعدام الشبكة، عزل الحساب، منع تسرب المستقبل، حدود بيانات OHLC، تكاليف Option Twin، اتجاه Call/Put، إيقاف الثقة عند الأعطال، ذاكرة القرار، عدم اختلاق Counterfactual، وثوقية GET في الخادم.

هذه الصفحة تصف الاختبارات المضافة؛ نتائج تشغيل Flutter Analyze والاختبارات تسجل من تشغيل CI الفعلي في تقرير تسليم RC2، ولا يُعد إنشاء الاختبارات نجاحًا في تشغيلها.
